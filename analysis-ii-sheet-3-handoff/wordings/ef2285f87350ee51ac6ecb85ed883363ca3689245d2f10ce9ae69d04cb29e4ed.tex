Quickies: (a) Show that two norms $\|\cdot\|$, $\|\cdot\|'$ on a vector space $V$ are Lipschitz equivalent if and only if there exist numbers $r,R>0$ such that $B_r\subseteq B'_1\subseteq B_R$, where $B_\rho=\{x\in V:\|x\|<\rho\}$ and $B'_\rho=\{x\in V:\|x\|'<\rho\}$.

(b) Show that two norms $\|\cdot\|$, $\|\cdot\|'$ on a vector space $V$ are Lipschitz equivalent if and only if the following holds: for any sequence $(x_n)$ in $V$, $x_n\to x$ with respect to $\|\cdot\|$ $\Longleftrightarrow$ $x_n\to x$ with respect to $\|\cdot\|'$.

(c) If $(V,\|\cdot\|)$ is a normed space and $\varphi:V\to\mathbb R$ is a linear functional, show that $\|\cdot\|+|\varphi(\cdot)|$ defines a norm on $V$, and that this norm is not Lipschitz equivalent to $\|\cdot\|$ if $\varphi$ is not continuous.

(d)$^\star$ Let $(V,\|\cdot\|)$ be a normed space. If any norm on $V$ is Lipschitz equivalent to $\|\cdot\|$, does it follow that $V$ is finite dimensional?
