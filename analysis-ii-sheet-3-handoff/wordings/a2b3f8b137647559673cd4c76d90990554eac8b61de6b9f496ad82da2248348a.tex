Let $f$ be a real-valued function on an open subset $U$ of $\mathbb R^2$ such that that $f(\cdot,y)$ is continuous for each fixed $y\in U$ and $f(x,\cdot)$ is continuous for each fixed $x\in U$. Give an example to show that $f$ need not be continuous on $U$. If additionally $f(\cdot,y)$ is Lipschitz for each $y\in U$ with Lipschitz constant independent of $y$, show that $f$ is continuous on $U$. Deduce that if $D_1 f$ exists and is bounded on $U$ and $f(x,\cdot)$ is continuous for each fixed $x\in U$, then $f$ is continuous on $U$.
