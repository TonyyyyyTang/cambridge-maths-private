(a) Let $(X,d)$ be a totally bounded metric space, that is $(X,d)$ has the property that for every $\epsilon>0$, there is a finite set $\{x_1,x_2,\ldots,x_N\}\subset X$ such that $X=\cup_{j=1}^N B_\epsilon(x_j)$. Show that any sequence $(x_k)$ in $X$ has a Cauchy subsequence. (b) Show that a metric space is compact if and only if it is complete and totally bounded.
