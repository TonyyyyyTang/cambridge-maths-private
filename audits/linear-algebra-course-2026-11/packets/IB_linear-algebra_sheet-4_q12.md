## Question (verbatim question.tex)
```latex
Prove Hadamard’s Inequality: if $A$ is a real $n\times n$ matrix and $k>0$ satisfies $|a_{i,j}|\le k$ for all $1\le i,j\le n$, then:
\[
|\det(A)|\le k^n n^{\frac{n}{2}}.
\]
```
