## Question (verbatim question.tex)
```latex
(a) Define a \emph{Givens rotation} $\Omega^{[p,q]}\in\mathbb{R}^{m\times m}$ and show that it is an orthogonal matrix.

(b) Define a $\mathsf{QR}$ \emph{factorization} of a matrix $\mathsf{A}\in\mathbb{R}^{m\times n}$ with $m\geq n$. Explain how Givens rotations can be used to find $\mathsf{Q}\in\mathbb{R}^{m\times m}$ and $\mathsf{R}\in\mathbb{R}^{m\times n}$.

(c) Let
\[
\mathsf{A}=\begin{bmatrix}3&1&1\\0&4&1\\0&3&2\\0&0&3/4\end{bmatrix},\qquad\mathbf{b}=\begin{bmatrix}98/25\\25\\25\\0\end{bmatrix}.
\]

(i) Find a $\mathsf{QR}$ factorization of $\mathsf{A}$ using Givens rotations.

(ii) Hence find the vector $\mathbf{x}^*\in\mathbb{R}^3$ which minimises $\|\mathsf{A}\mathbf{x}-\mathbf{b}\|$, where $\|\cdot\|$ is the Euclidean norm. What is $\|\mathsf{A}\mathbf{x}^*-\mathbf{b}\|$?
```
