## Question (verbatim question.tex)
```latex
For a numerical method for solving $y'=f(t,y)$, define the linear stability domain, and state when such a method is A-stable.

Determine all values of the real parameter $a$ for which the Runge-Kutta method
\[
\begin{aligned}
k_1&=f\Bigl(t_n+(\tfrac12-a)h,y_n+\left(\tfrac14hk_1+(\tfrac14-a)hk_2\right)\Bigr),\\
k_2&=f\Bigl(t_n+(\tfrac12+a)h,y_n+\left((\tfrac14+a)hk_1+\tfrac14hk_2\right)\Bigr),\\
y_{n+1}&=y_n+\tfrac12 h(k_1+k_2)
\end{aligned}
\]
is A-stable.
```
