## Question (verbatim question.tex)
```latex
Define a Householder transformation $\mathsf H$ and show that it is an orthogonal matrix. Briefly explain how these transformations can be used for $\mathsf{QR}$ factorisation of an $m\times n$ matrix.

Using Householder transformations, find a $\mathsf{QR}$ factorisation of
\[
\mathsf A=\begin{bmatrix}2&5&4\\2&5&1\\-2&1&5\\2&-1&16\end{bmatrix}.
\]
Using this factorisation, find the value of $\lambda$ for which
\[
\mathsf A\,x=\begin{bmatrix}1+\lambda\\2\\3\\4\end{bmatrix}
\]
has a unique solution $x\in\mathbb R^3$.
```
