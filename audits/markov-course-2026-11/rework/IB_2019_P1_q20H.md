## Full Solution

Let $S$ denote the state space, with $|S| = N < \infty$ ($N \ge 1$). Since $P$ is irreducible on the finite state space $S$, it is positive recurrent and has a unique invariant distribution $\pi$ (satisfying $\pi P = \pi$ and $\sum_{x \in S} \pi(x) = 1$).

**Preliminary observation: $\pi(x) > 0$ for all $x \in S$.**
Because $\sum_{w \in S} \pi(w) = 1$, there exists some $z \in S$ with $\pi(z) > 0$. By irreducibility, for every $x \in S$ there exists $n \ge 0$ such that $P^n(z, x) > 0$. Since $\pi$ is invariant, $\pi P^n = \pi$, so
\[
\pi(x) = \sum_{w \in S} \pi(w) P^n(w, x) \ge \pi(z) P^n(z, x) > 0.
\]
Moreover, because $X_0 \sim \pi$ and $\pi P = \pi$, we have $X_n \sim \pi$ for all $n \ge 0$; in particular,
\[
\mathbb{P}(X_1 = x) = \sum_{w \in S} \mathbb{P}(X_0 = w) P(w, x) = \sum_{w \in S} \pi(w) P(w, x) = \pi(x) > 0 \qquad \text{for all } x \in S.
\]

---

### Part (a)

Since $\mathbb{P}(X_1 = x) = \pi(x) > 0$ for every $x \in S$, the conditional probability $P^*(x, y) = \mathbb{P}[X_0 = y \mid X_1 = x]$ is well-defined for all $x, y \in S$. By the definition of conditional probability,
\[
P^*(x, y)
= \mathbb{P}[X_0 = y \mid X_1 = x]
= \frac{\mathbb{P}(X_0 = y, X_1 = x)}{\mathbb{P}(X_1 = x)}
= \frac{\mathbb{P}(X_0 = y)\,\mathbb{P}(X_1 = x \mid X_0 = y)}{\pi(x)}
= \frac{\pi(y) P(y, x)}{\pi(x)}.
\]

*(Note for part (c): $P^*$ is indeed a valid stochastic matrix on $S$, since $P^*(x, y) \ge 0$ and $\sum_{y \in S} P^*(x, y) = \frac{1}{\pi(x)} \sum_{y \in S} \pi(y) P(y, x) = \frac{\pi(x)}{\pi(x)} = 1$, and $\pi$ is also invariant for $P^*$.)*

---

### Part (b)

For each state $x \in S$, let $T_x = \min\{n \ge 1 : X_n = x\}$ be the first return time to $x$. On the event $\{X_0 = x\}$, we have $T = \min\{n \ge 1 : X_n = X_0\} = T_x$.

Because $(X_n)$ is irreducible on the finite state space $S$ (hence positive recurrent) with unique invariant distribution $\pi$ (and $\pi(x) > 0$ for all $x \in S$), the standard theorem on expected return times gives, for every $x \in S$,
\[
\mathbb{P}(T < \infty \mid X_0 = x) = \mathbb{P}_x(T_x < \infty) = 1
\qquad \text{and} \qquad
\mathbb{E}[T \mid X_0 = x] = \mathbb{E}_x[T_x] = \frac{1}{\pi(x)}.
\]
By the law of total expectation (summing over the finite state space $S$),
\[
\mathbb{E}[T]
= \sum_{x \in S} \mathbb{P}(X_0 = x)\,\mathbb{E}[T \mid X_0 = x]
= \sum_{x \in S} \pi(x) \cdot \frac{1}{\pi(x)}
= \sum_{x \in S} 1
= N.
\]

### Part (c)

Let $Z \sim \pi$ be the common starting state of the cop and the robber, let $R$ be the state occupied by the robber after taking one step from $Z$ according to $P^*$, and let $(C_n)_{n \ge 0}$ be the cop's trajectory, where $C_0 = Z$ and, conditional on $(R, Z)$, $(C_n)_{n \ge 0}$ evolves as a Markov chain with transition matrix $P$ independently of $R$.

The time taken by the cop to catch the robber (i.e., to visit state $R$) is
\[
\tau = \min\{n \ge 0 : C_n = R\}.
\]
(In particular, if $R = Z$, so the robber's step according to $P^*$ stays at the starting state $Z$, then $C_0 = R$ and the cop catches the robber immediately at time $\tau = 0$.)

**Method 1 (Distributional identification with the stationary chain $(X_n)$).**
For any integer $k \ge 0$ and any states $y, x_0, x_1, \dots, x_k \in S$, using the conditional independence of the cop's steps from $R$ given $C_0 = Z = x_0$, and substituting $\pi(x_0) P^*(x_0, y) = \pi(y) P(y, x_0)$ from part (a), we compute
\[
\begin{aligned}
\mathbb{P}(R = y, C_0 = x_0, C_1 = x_1, \dots, C_k = x_k)
&= \mathbb{P}(Z = x_0)\,\mathbb{P}(R = y \mid Z = x_0)\,P(x_0, x_1)\cdots P(x_{k-1}, x_k) \\
&= \pi(x_0) P^*(x_0, y) P(x_0, x_1)\cdots P(x_{k-1}, x_k) \\
&= \pi(y) P(y, x_0) P(x_0, x_1)\cdots P(x_{k-1}, x_k) \\
&= \mathbb{P}(X_0 = y, X_1 = x_0, X_2 = x_1, \dots, X_{k+1} = x_k),
\end{aligned}
\]
where $(X_n)_{n \ge 0}$ is the stationary Markov chain with $X_0 \sim \pi$ and transition matrix $P$.

Thus $(R, C_0, C_1, \dots, C_k) \stackrel{d}{=} (X_0, X_1, X_2, \dots, X_{k+1})$ for every $k \ge 0$. Since the event $\{\tau = k\}$ depends only on $(R, C_0, \dots, C_k)$, namely
\[
\{\tau = k\} = \{C_0 \ne R,\, C_1 \ne R,\, \dots,\, C_{k-1} \ne R,\, C_k = R\},
\]
we obtain for every $k \ge 0$:
\[
\mathbb{P}(\tau = k)
= \mathbb{P}(X_1 \ne X_0,\, X_2 \ne X_0,\, \dots,\, X_k \ne X_0,\, X_{k+1} = X_0)
= \mathbb{P}(T = k + 1),
\]
where $T = \min\{m \ge 1 : X_m = X_0\}$ is the return time from part (b).

In particular, $\sum_{k=0}^\infty \mathbb{P}(\tau = k) = \sum_{m=1}^\infty \mathbb{P}(T = m) = 1$, so $\tau < \infty$ almost surely, and $\tau \stackrel{d}{=} T - 1$. Hence, by part (b),
\[
\mathbb{E}[\tau]
= \sum_{k=0}^\infty k\,\mathbb{P}(\tau = k)
= \sum_{k=0}^\infty k\,\mathbb{P}(T = k + 1)
= \sum_{m=1}^\infty (m - 1)\,\mathbb{P}(T = m)
= \mathbb{E}[T] - 1
= N - 1.
\]

*(Alternative verification via first-step hitting times: Let $h(x, y) = \mathbb{E}_x[\min\{n \ge 0 : X_n = y\}]$ (with $h(y, y) = 0$). Conditioning on $X_1$ in $\mathbb{E}_y[T_y]$ gives $1/\pi(y) = \mathbb{E}_y[T_y] = 1 + \sum_{x \in S} P(y, x)\,h(x, y)$. Multiplying by $\pi(y)$, summing over $y \in S$, and using part (a) ($\pi(y)P(y,x) = \pi(x)P^*(x,y)$) yields $N = 1 + \sum_{x, y \in S} \pi(x) P^*(x, y)\,h(x, y) = 1 + \mathbb{E}[\tau]$, confirming $\mathbb{E}[\tau] = N - 1$.)*
