## Full Solution

Let $\mathbb{P}_u$ and $\mathbb{E}_u$ denote probability and expectation for the Markov chain $X = (X_n)_{n \ge 0}$ started from $X_0 = u \in S$.

### Part (a)

Define the first return time to $v$ by
\[
T_v = \inf\{n \ge 1 : X_n = v\} \qquad (\text{with } \inf\emptyset = \infty),
\]
and let $f_v = \mathbb{P}_v(T_v < \infty)$ be the probability that the chain ever returns to $v$ starting from $v$. By definition, $X$ is **recurrent** at $v$ if $f_v = 1$ (equivalently, $\mathbb{P}_v(X_n = v \text{ for infinitely many } n) = 1$).

Let
\[
V_v = \sum_{n=0}^{\infty} \mathbf{1}_{\{X_n = v\}}
\]
be the total number of visits to $v$ (including time $n = 0$), and let
\[
R_v = \sum_{n=1}^{\infty} \mathbf{1}_{\{X_n = v\}}
\]
be the total number of returns to $v$ after time $0$. Under $\mathbb{P}_v$ (where $X_0 = v$ almost surely), we have $V_v = 1 + R_v$.

By the given fact that $R_v$ under $\mathbb{P}_v$ has the geometric distribution (with failure/return probability $f_v = \mathbb{P}_v(T_v < \infty)$), we have for every integer $k \ge 0$:
\[
\mathbb{P}_v(R_v \ge k) = f_v^k
\]
(corresponding to $\mathbb{P}_v(R_v = k) = f_v^k (1 - f_v)$ when $f_v < 1$, and the degenerate geometric distribution at $\infty$ when $f_v = 1$).

Since $X$ is recurrent at $v$, we have $f_v = 1$. Therefore, for every integer $k \ge 0$,
\[
\mathbb{P}_v(R_v \ge k) = 1^k = 1.
\]
Hence, by continuity of probability from above for the decreasing events $\{R_v \ge k\}$,
\[
\mathbb{P}_v(R_v = \infty) = \lim_{k \to \infty} \mathbb{P}_v(R_v \ge k) = 1,
\]
and consequently $\mathbb{P}_v(V_v = \infty) = 1$, which implies $\mathbb{E}_v[V_v] = \infty$.

Now define the partial sums $S_N = \sum_{n=0}^{N} \mathbf{1}_{\{X_n = v\}}$ for $N \ge 0$. Then $0 \le S_0 \le S_1 \le \cdots$ and $S_N \uparrow V_v$ pointwise as $N \to \infty$. By the Monotone Convergence Theorem (and linearity of expectation on each finite sum $S_N$),
\[
\sum_{n=0}^{\infty} p_{vv}(n)
= \lim_{N \to \infty} \sum_{n=0}^{N} \mathbb{P}_v(X_n = v)
= \lim_{N \to \infty} \mathbb{E}_v[S_N]
= \mathbb{E}_v[V_v]
= \infty.
\]

*(Elementary justification of the divergence without invoking MCT by name: for any fixed integer $K \ge 1$, Markov's inequality on $S_N$ gives $\sum_{n=0}^{N} p_{vv}(n) = \mathbb{E}_v[S_N] \ge K\,\mathbb{P}_v(S_N \ge K)$. As $N \to \infty$, the events $\{S_N \ge K\}$ increase to $\{V_v \ge K\} = \{R_v \ge K - 1\}$, so continuity of probability from below gives $\sum_{n=0}^{\infty} p_{vv}(n) \ge K\,\mathbb{P}_v(R_v \ge K - 1) = K$. Since $K \ge 1$ is arbitrary, $\sum_{n=0}^{\infty} p_{vv}(n) = \infty$.)*

### Part (b)

Let $X = (X_n)_{n \ge 0}$ and $Y = (Y_n)_{n \ge 0}$ be independent simple symmetric random walks on $\mathbb{Z}^2$ with $X_0 = Y_0 = 0 = (0,0)$, and let $Z = \sum_{n=0}^{\infty} \mathbf{1}_{\{X_n = Y_n\}}$.

1. **Proof that $\mathbb{E}[Z] = \sum_{n=0}^{\infty} p_{00}(2n)$.**

   Since each indicator $\mathbf{1}_{\{X_n = Y_n\}}$ is non-negative, the partial sums $\sum_{n=0}^{N} \mathbf{1}_{\{X_n = Y_n\}}$ increase monotonically to $Z$. By the Monotone Convergence Theorem (or Tonelli's theorem for non-negative summands),
   \[
   \mathbb{E}[Z] = \mathbb{E}\!\left[\sum_{n=0}^{\infty} \mathbf{1}_{\{X_n = Y_n\}}\right] = \sum_{n=0}^{\infty} \mathbb{E}\!\left[\mathbf{1}_{\{X_n = Y_n\}}\right] = \sum_{n=0}^{\infty} \mathbb{P}(X_n = Y_n).
   \]
   Fix $n \ge 0$. Since $\mathbb{Z}^2$ is countable, the event $\{X_n = Y_n\}$ is the countable disjoint union $\bigsqcup_{x \in \mathbb{Z}^2} \{X_n = x,\, Y_n = x\}$. By countable additivity, independence of $X$ and $Y$, and the fact that $X$ and $Y$ have the same transition probabilities and both start at $0$:
   \[
   \mathbb{P}(X_n = Y_n)
   = \sum_{x \in \mathbb{Z}^2} \mathbb{P}(X_n = x,\, Y_n = x)
   = \sum_{x \in \mathbb{Z}^2} \mathbb{P}(X_n = x)\,\mathbb{P}(Y_n = x)
   = \sum_{x \in \mathbb{Z}^2} p_{0x}(n)\,p_{0x}(n).
   \]
   We are given that $p_{xy}(n) = p_{yx}(n)$ for all $x, y \in \mathbb{Z}^2$ and $n \in \mathbb{N}$; this also holds trivially for $n = 0$ since $p_{xy}(0) = \delta_{xy} = p_{yx}(0)$. Hence $p_{0x}(n) = p_{x0}(n)$ for all $x \in \mathbb{Z}^2$ and all $n \ge 0$, so
   \[
   \mathbb{P}(X_n = Y_n) = \sum_{x \in \mathbb{Z}^2} p_{0x}(n)\,p_{x0}(n).
   \]
   By the Chapman–Kolmogorov equations (obtained by partitioning $\{X_{2n} = 0\}$ according to $X_n = x$ and applying the Markov property at time $n$:
   \[
   p_{00}(2n) = \sum_{x \in \mathbb{Z}^2} \mathbb{P}_0(X_n = x,\, X_{2n} = 0) = \sum_{x \in \mathbb{Z}^2} p_{0x}(n)\,p_{x0}(n),
   \]
   where terms with $p_{0x}(n) = 0$ contribute $0$ on both sides), it follows that
   \[
   \mathbb{P}(X_n = Y_n) = p_{00}(2n) \qquad \text{for all } n \ge 0.
   \]
   Summing over all $n \ge 0$ yields
   \[
   \mathbb{E}[Z] = \sum_{n=0}^{\infty} p_{00}(2n).
   \]

2. **Deduction that $\mathbb{E}[Z] = \infty$.**

   For a simple symmetric random walk $X$ on $\mathbb{Z}^2$, each step adds one of $(\pm 1, 0)$ or $(0, \pm 1)$ to the current position. Writing $X_m = (X_m^{(1)}, X_m^{(2)})$, the coordinate sum $X_m^{(1)} + X_m^{(2)}$ changes by $\pm 1$ at every step, so its parity alternates:
   \[
   X_{m+1}^{(1)} + X_{m+1}^{(2)} \equiv X_m^{(1)} + X_m^{(2)} + 1 \pmod 2 \qquad \text{for all } m \ge 0.
   \]
   Since $X_0 = (0,0)$ has $0 + 0 \equiv 0 \pmod 2$, induction on $m$ gives
   \[
   X_m^{(1)} + X_m^{(2)} \equiv m \pmod 2 \qquad \text{for all } m \ge 0.
   \]
   In particular, for every odd time $m = 2n + 1$ ($n \ge 0$), we have $X_{2n+1}^{(1)} + X_{2n+1}^{(2)} \equiv 1 \pmod 2$, whereas the origin $(0,0)$ has coordinate sum $0 \equiv 0 \pmod 2$. Therefore $X_{2n+1} \ne 0$ surely, so
   \[
   p_{00}(2n + 1) = 0 \qquad \text{for all } n \ge 0.
   \]
   Consequently,
   \[
   \mathbb{E}[Z] = \sum_{n=0}^{\infty} p_{00}(2n) = \sum_{n=0}^{\infty} \bigl(p_{00}(2n) + p_{00}(2n+1)\bigr) = \sum_{m=0}^{\infty} p_{00}(m).
   \]
   Since $X$ is given to be recurrent at $0$, part (a) implies $\sum_{m=0}^{\infty} p_{00}(m) = \infty$. Hence
   \[
   \mathbb{E}[Z] = \infty.
   \]

## Confidence & Edge-Case Notes

- **Confidence:** `high`
- **Subtleties / pitfalls to watch during Phase B:**
  1. **Parity step in part (b):** Simply saying "$\sum_{n=0}^\infty p_{00}(2n) = \infty$ by part (a)" without proving $p_{00}(2n+1) = 0$ is a gap, because part (a) gives $\sum_{m=0}^\infty p_{00}(m) = \infty$, not automatically the even subseries.
  2. **Justification of $\mathbb{E}[\sum_{n=0}^\infty \mathbf{1}_{A_n}] = \sum_{n=0}^\infty \mathbb{P}(A_n)$:** Requires MCT/Tonelli (non-negativity of indicators), not mere finite linearity of expectation.
  3. **Number of returns vs. number of visits in part (a):** $R_v = \sum_{n=1}^\infty \mathbf{1}_{\{X_n = v\}} = V_v - 1$ under $\mathbb{P}_v$; when $f_v = 1$, the geometric distribution is degenerate at $\infty$, so care should be taken not to write $\frac{1}{1 - f_v}$ without handling $f_v = 1$ via $\mathbb{P}_v(R_v \ge k) = f_v^k = 1$.
  4. **$n = 0$ case in symmetry $p_{xy}(n) = p_{yx}(n)$:** Since $\mathbb{N}$ can mean $\{1, 2, \ldots\}$, explicitly noting $p_{0x}(0) = \delta_{0x} = p_{x0}(0)$ closes that tiny convention edge case.
