## Full Solution

### Setup, Stochasticity, and Irreducibility

Here $I = \mathbb{Z}^+ = \{0, 1, 2, \ldots\}$. The statement specifies that the non-zero transition probabilities are $p_{00} = q_0$ and $p_{i,i+1} = p_i$, $p_{i+1,i} = q_{i+1}$ for all $i \in I$, with all other $p_{ij} = 0$. In particular:
- $p_i > 0$ for all $i \geqslant 0$, $q_i > 0$ for all $i \geqslant 1$, and $q_0 > 0$.
- Since $P = (p_{ij})_{i,j \in I}$ is a stochastic matrix (every row sums to $1$):
  $$q_0 + p_0 = 1, \qquad q_i + p_i = 1 \quad (i \geqslant 1).$$
  Thus $p_i, q_i \in (0, 1)$ for all $i \geqslant 0$, so all ratios $q_r / p_r$ and $p_{r-1} / q_r$ ($r \geqslant 1$) are well-defined and strictly positive.
  *(Remark: even if $q_0 = 0$ and $p_0 = 1$ were permitted as a boundary case, every step of the proof below remains valid without change, since only $p_0 > 0$, $q_0 + p_0 = 1$, and $p_i, q_i > 0$ for $i \geqslant 1$ are used.)*

**Irreducibility.** For any $i, j \in I$ with $i < j$,
$$p_{ij}^{(j-i)} \geqslant p_i p_{i+1} \cdots p_{j-1} > 0, \qquad p_{ji}^{(j-i)} \geqslant q_j q_{j-1} \cdots q_{i+1} > 0.$$
Hence every pair of states communicates ($i \leftrightarrow j$ for all $i, j \in I$), so the Markov chain $(X_n)_{n \geqslant 0}$ is **irreducible**. Because recurrence and positive-recurrence are class properties for Markov chains, the chain is recurrent (respectively, positive-recurrent) if and only if state $0$ is recurrent (respectively, positive-recurrent).

### Part 1: Criterion for Recurrence

Let
$$H_k = \inf\{n \geqslant 0 : X_n = k\}, \qquad T_0 = \inf\{n \geqslant 1 : X_n = 0\}$$
(with $\inf \emptyset = \infty$), and write $h_i = \mathbb{P}_i(H_0 < \infty) = \mathbb{P}(H_0 < \infty \mid X_0 = i)$.

**Step 1: Reduction to $h_1$.**
Conditioning on $X_1$ starting from $X_0 = 0$ and using the Markov property at time $1$:
$$\mathbb{P}_0(T_0 < \infty) = p_{00} \cdot 1 + p_{01}\,\mathbb{P}_1(H_0 < \infty) = q_0 + p_0 h_1.$$
Since $q_0 = 1 - p_0$, this becomes
$$\mathbb{P}_0(T_0 < \infty) = 1 - p_0(1 - h_1).$$
As $p_0 > 0$, state $0$ is recurrent ($\mathbb{P}_0(T_0 < \infty) = 1$) if and only if $h_1 = 1$.

**Step 2: Exact computation of $h_1$ via finite truncation.**
For each integer $N \geqslant 1$ and $0 \leqslant i \leqslant N$, define
$$u_i^{(N)} = \mathbb{P}_i(H_0 < H_N).$$
Clearly $u_0^{(N)} = 1$ (since $H_0 = 0 < H_N$ when $X_0 = 0$ and $N \geqslant 1$) and $u_N^{(N)} = 0$ (since $H_N = 0 < H_0$ when $X_0 = N$). For $1 \leqslant i \leqslant N - 1$, conditioning on $X_1$ and applying the Markov property at time $1$ gives
$$u_i^{(N)} = p_i u_{i+1}^{(N)} + q_i u_{i-1}^{(N)} \qquad (1 \leqslant i \leqslant N - 1).$$
*(Note that on $\{X_0 = i\}$ with $1 \leqslant i \leqslant N-1$, the event $\{H_0 < H_N\}$ coincides with $\{\tilde{H}_0 < \tilde{H}_N\}$ for the shifted chain $\tilde{X}_m = X_{m+1}$, including the case where both hitting times are $\infty$, since $\infty < \infty$ is false.)*

Since $p_i + q_i = 1$, rewrite this recurrence as
$$p_i\bigl(u_{i+1}^{(N)} - u_i^{(N)}\bigr) = q_i\bigl(u_i^{(N)} - u_{i-1}^{(N)}\bigr) \qquad (1 \leqslant i \leqslant N - 1).$$
Setting $\Delta_n = u_n^{(N)} - u_{n-1}^{(N)}$ for $1 \leqslant n \leqslant N$, we have
$$\Delta_{i+1} = \frac{q_i}{p_i}\Delta_i \qquad (1 \leqslant i \leqslant N - 1).$$
Define
$$\gamma_0 = 1, \qquad \gamma_n = \prod_{r=1}^n \frac{q_r}{p_r} \quad (n \geqslant 1).$$
By induction on $n$, $\Delta_n = \gamma_{n-1} \Delta_1$ for $1 \leqslant n \leqslant N$. Summing from $n = 1$ to $N$ telescopes to
$$-1 = u_N^{(N)} - u_0^{(N)} = \sum_{n=1}^N \Delta_n = \Delta_1 \sum_{k=0}^{N-1} \gamma_k.$$
Since every $\gamma_k > 0$, we obtain
$$\Delta_1 = -\frac{1}{\sum_{k=0}^{N-1} \gamma_k},$$
and hence (as $\Delta_1 = u_1^{(N)} - u_0^{(N)} = u_1^{(N)} - 1$):
$$u_1^{(N)} = 1 - \frac{1}{\sum_{k=0}^{N-1} \gamma_k} = 1 - \frac{1}{1 + \sum_{n=1}^{N-1} \prod_{r=1}^n \frac{q_r}{p_r}}.$$
*(More generally, $u_i^{(N)} = \bigl(\sum_{k=i}^{N-1} \gamma_k\bigr) \big/ \bigl(\sum_{k=0}^{N-1} \gamma_k\bigr)$ for $0 \leqslant i \leqslant N$.)*

**Step 3: Passing to the limit $N \to \infty$.**
Let $\Omega_0 = \{\forall k \geqslant 0, \; |X_{k+1} - X_k| \leqslant 1\}$. Since $p_{ij} = 0$ whenever $|i - j| > 1$, we have $\mathbb{P}_1(\Omega_0) = 1$. On $\Omega_0$ with $X_0 = 1$:
1. To reach $N+1$ from $1 < N$, the chain must first visit $N$, so $H_N \leqslant H_{N+1}$ (with strict inequality whenever $H_{N+1} < \infty$). Therefore the events $E_N = \{H_0 < H_N\} \cap \Omega_0$ are increasing: $E_1 \subseteq E_2 \subseteq \cdots$.
2. We claim $\bigcup_{N=1}^\infty E_N = \{H_0 < \infty\} \cap \Omega_0$:
   - If $\omega \in E_N$, then $H_0(\omega) < H_N(\omega) \leqslant \infty$, so $H_0(\omega) < \infty$.
   - Conversely, if $\omega \in \{H_0 < \infty\} \cap \Omega_0$ and $H_0(\omega) = m < \infty$, then $X_k(\omega) \leqslant 1 + k \leqslant 1 + m$ for all $0 \leqslant k \leqslant m$; choosing $N = m + 2$ gives $H_N(\omega) > m = H_0(\omega)$, so $\omega \in E_N$.

By continuity of probability from below:
$$h_1 = \mathbb{P}_1(H_0 < \infty) = \lim_{N \to \infty} \mathbb{P}_1(E_N) = \lim_{N \to \infty} u_1^{(N)} = 1 - \frac{1}{1 + \sum_{n \geqslant 1} \prod_{r=1}^n \frac{q_r}{p_r}},$$
with the convention $1/\infty = 0$.

Therefore:
$$\text{the chain is recurrent} \iff \text{state } 0 \text{ is recurrent} \iff h_1 = 1 \iff \sum_{n \geqslant 1} \prod_{r=1}^n \frac{q_r}{p_r} = \infty.$$

*(Alternative via minimal non-negative solution: $(h_i)_{i \in I}$ is the minimal non-negative solution to $g_0 = 1$ and $g_i = p_i g_{i+1} + q_i g_{i-1}$ for $i \geqslant 1$. Every solution has the form $g_n = 1 + (g_1 - 1)\sum_{k=0}^{n-1}\gamma_k$, which stays non-negative for all $n \geqslant 0$ iff $g_1 - 1 \geqslant -1 / \sum_{k=0}^\infty \gamma_k$; minimising gives $h_1 = 1 - 1/\sum_{k=0}^\infty \gamma_k$, leading to the same conclusion.)*

### Part 2: Criterion for Positive-Recurrence

We use the standard Part IB theorem: **an irreducible Markov chain is positive-recurrent if and only if it possesses an invariant distribution** (a vector $\pi = (\pi_i)_{i \in I}$ with $\pi_i \geqslant 0$, $\sum_{i \in I} \pi_i = 1$, and $\pi P = \pi$). We already proved that $(X_n)$ is irreducible.

**Step 1: Solving the invariant measure equations $\pi P = \pi$.**
The equations $(\pi P)_j = \pi_j$ read:
- For $j = 0$:
  $$\pi_0 = \pi_0 p_{00} + \pi_1 p_{10} = \pi_0 q_0 + \pi_1 q_1.$$
  Since $1 - q_0 = p_0$, this rearranges to
  $$q_1 \pi_1 - p_0 \pi_0 = 0.$$
- For $j \geqslant 1$:
  $$\pi_j = \pi_{j-1} p_{j-1,j} + \pi_{j+1} p_{j+1,j} = \pi_{j-1} p_{j-1} + \pi_{j+1} q_{j+1}.$$
  Writing $\pi_j = (p_j + q_j)\pi_j$, this rearranges to
  $$q_{j+1} \pi_{j+1} - p_j \pi_j = q_j \pi_j - p_{j-1} \pi_{j-1} \qquad (j \geqslant 1).$$

By induction on $j \geqslant 0$, the quantity $q_{j+1}\pi_{j+1} - p_j \pi_j$ is constant in $j$ and equal to its value at $j = 0$, which is $0$. Thus every solution of $\pi P = \pi$ satisfies the detailed balance equations
$$q_{j+1}\pi_{j+1} = p_j \pi_j \qquad (j \geqslant 0),$$
and conversely any sequence satisfying $q_{j+1}\pi_{j+1} = p_j \pi_j$ ($j \geqslant 0$) satisfies $\pi P = \pi$ (checking $j = 0$: $\pi_0 q_0 + \pi_1 q_1 = \pi_0(q_0 + p_0) = \pi_0$; checking $j \geqslant 1$: $\pi_{j-1}p_{j-1} + \pi_{j+1}q_{j+1} = \pi_j(q_j + p_j) = \pi_j$).

Since $q_r > 0$ for all $r \geqslant 1$, iterating $\pi_r = \frac{p_{r-1}}{q_r}\pi_{r-1}$ gives the general solution to $\pi P = \pi$:
$$\pi_n = \pi_0 a_n \quad (n \geqslant 0), \qquad \text{where } a_0 = 1 \text{ and } a_n = \prod_{r=1}^n \frac{p_{r-1}}{q_r} > 0 \quad (n \geqslant 1).$$

**Step 2: Existence of an invariant distribution.**
Write
$$S = \sum_{n=0}^\infty a_n = 1 + \sum_{n \geqslant 1} \prod_{r=1}^n \frac{p_{r-1}}{q_r} \in (1, \infty].$$
- **($\Leftarrow$) Suppose $\sum_{n \geqslant 1} \prod_{r=1}^n \frac{p_{r-1}}{q_r} < \infty$.**
  Then $S < \infty$. Defining $\pi_n = a_n / S$ for $n \geqslant 0$ gives $\pi_n > 0$ for all $n \in I$, $\sum_{n=0}^\infty \pi_n = 1$, and $\pi P = \pi$. Thus $\pi$ is an invariant distribution. Since the chain is irreducible, it is **positive-recurrent**.
- **($\Rightarrow$) Suppose the chain is positive-recurrent.**
  Since it is irreducible, it admits an invariant distribution $\pi$ (with $\pi_n \geqslant 0$, $\sum_{n=0}^\infty \pi_n = 1$, and $\pi P = \pi$). By Step 1, $\pi_n = \pi_0 a_n$ for all $n \geqslant 0$. We must have $\pi_0 > 0$ (otherwise $\pi_n = 0$ for all $n$, contradicting $\sum_{n=0}^\infty \pi_n = 1$). Therefore
  $$1 = \sum_{n=0}^\infty \pi_n = \pi_0 S \implies S = \frac{1}{\pi_0} < \infty,$$
  and hence $\sum_{n \geqslant 1} \prod_{r=1}^n \frac{p_{r-1}}{q_r} = S - 1 < \infty$.

*(Consistency remark: $a_n \gamma_n = \prod_{r=1}^n \frac{p_{r-1}q_r}{q_r p_r} = \frac{p_0}{p_n} \geqslant p_0 > 0$, so $\sum a_n < \infty \implies a_n \to 0 \implies \gamma_n \geqslant p_0/a_n \to \infty \implies \sum \gamma_n = \infty$, directly reflecting that positive-recurrence implies recurrence. Moreover, when positive-recurrent, $\mathbb{E}_0(T_0) = 1/\pi_0 = 1 + \sum_{n \geqslant 1}\prod_{r=1}^n \frac{p_{r-1}}{q_r}$.)*

## Final Answers

- **Recurrence:** The chain is irreducible and is recurrent if and only if
  $$\sum_{n \geqslant 1} \prod_{r=1}^n \frac{q_r}{p_r} = \infty$$
  (with hitting probability $h_1 = \mathbb{P}_1(H_0 < \infty) = 1 - \bigl(1 + \sum_{n \geqslant 1}\prod_{r=1}^n \frac{q_r}{p_r}\bigr)^{-1}$).
- **Positive-recurrence:** The chain is positive-recurrent if and only if
  $$\sum_{n \geqslant 1} \prod_{r=1}^n \frac{p_{r-1}}{q_r} < \infty$$
  (in which case the unique invariant distribution is $\pi_n = \pi_0 \prod_{r=1}^n \frac{p_{r-1}}{q_r}$ for $n \geqslant 1$, with $\pi_0 = \bigl(1 + \sum_{n \geqslant 1}\prod_{r=1}^n \frac{p_{r-1}}{q_r}\bigr)^{-1} = 1/\mathbb{E}_0(T_0)$).

## Confidence & Edge-Case Notes

- **Confidence:** `high`.
- **Subtleties / Phase B watch-items:**
  1. **Irreducibility must be explicitly verified**, because both parts rely on it (recurrence is a class property, and existence of an invariant distribution is equivalent to positive-recurrence *only* for irreducible chains).
  2. **Boundary at $0$:** Row $0$ has $q_0 + p_0 = 1$ with $p_{00} = q_0 > 0$ (though $q_0 = 0, p_0 = 1$ also works). Note that $\mathbb{P}_0(T_0 < \infty) = q_0 + p_0 h_1 = 1 - p_0(1 - h_1)$ requires $p_0 > 0$ to equate recurrence of $0$ with $h_1 = 1$.
  3. **Justification of $\lim_{N \to \infty} u_1^{(N)} = h_1$** (or of minimality of the non-negative solution to the hitting-probability equations): a common gap is writing the recurrence for $h_i$ and claiming $h_i \to 0$ as $i \to \infty$ without justification (indeed, in the recurrent case $h_i \equiv 1$, and even in the transient case $\lim_{i \to \infty} h_i = 0$ is a consequence of minimality or truncation, not an assumption!).
  4. **In Part 2, showing $\pi P = \pi$ forces detailed balance $q_{j+1}\pi_{j+1} = p_j \pi_j$** is essential for the "only if" direction: merely checking that $\pi_n = \pi_0 \prod_{r=1}^n (p_{r-1}/q_r)$ is *a* solution to $\pi P = \pi$ does not rule out other solutions unless one proves uniqueness up to a scalar multiple (by induction from $j = 0$, or via uniqueness of invariant measure on an irreducible recurrent chain).
