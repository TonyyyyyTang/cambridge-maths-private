### Part (a): $W_n = X_{2n}$

Let $\lambda = (\lambda_i : i \in S)$ be the initial distribution of $(X_n : n \ge 0)$, where $\lambda_i = \mathbb{P}(X_0 = i)$.

**Standard results from IB Markov Chains used:**
1. *Finite-dimensional distribution characterisation*: A sequence of $S$-valued random variables $(Z_n : n \ge 0)$ is a homogeneous Markov chain with initial distribution $\mu$ and stochastic transition matrix $Q = (q_{i,j} : i,j \in S)$ if and only if, for all $n \ge 0$ and all $i_0, i_1, \ldots, i_n \in S$,
   \[
   \mathbb{P}(Z_0 = i_0, Z_1 = i_1, \ldots, Z_n = i_n) = \mu_{i_0} q_{i_0, i_1} q_{i_1, i_2} \cdots q_{i_{n-1}, i_n}.
   \]

**Proof that $(W_n : n \ge 0)$ is a Markov chain with transition matrix $P^2$:**
First, let $Q = P^2$, whose entries are
\[
q_{i,j} = (P^2)_{i,j} = \sum_{k \in S} p_{i,k} p_{k,j}, \qquad i, j \in S.
\]
Clearly $Q$ is a stochastic matrix: $q_{i,j} \ge 0$ for all $i, j \in S$, and since all terms are non-negative we may interchange the countable sums to obtain
\[
\sum_{j \in S} q_{i,j} = \sum_{j \in S} \sum_{k \in S} p_{i,k} p_{k,j} = \sum_{k \in S} p_{i,k} \left(\sum_{j \in S} p_{k,j}\right) = \sum_{k \in S} p_{i,k} \cdot 1 = 1 \qquad \forall\, i \in S.
\]

Now fix any $n \ge 0$ and any $i_0, i_1, \ldots, i_n \in S$. By countable additivity over the disjoint events indexing the odd-time values $X_1 = j_1, X_3 = j_2, \ldots, X_{2n-1} = j_n$, and using the finite-dimensional distribution of the homogeneous Markov chain $(X_m : m \ge 0)$:
\[
\begin{aligned}
\mathbb{P}(W_0 = i_0, W_1 = i_1, \ldots, W_n = i_n)
&= \mathbb{P}(X_0 = i_0, X_2 = i_1, \ldots, X_{2n} = i_n) \\
&= \sum_{j_1 \in S} \sum_{j_2 \in S} \cdots \sum_{j_n \in S} \mathbb{P}(X_0 = i_0, X_1 = j_1, X_2 = i_1, \ldots, X_{2n-1} = j_n, X_{2n} = i_n) \\
&= \sum_{j_1 \in S} \sum_{j_2 \in S} \cdots \sum_{j_n \in S} \lambda_{i_0} p_{i_0, j_1} p_{j_1, i_1} p_{i_1, j_2} p_{j_2, i_2} \cdots p_{i_{n-1}, j_n} p_{j_n, i_n} \\
&= \lambda_{i_0} \left(\sum_{j_1 \in S} p_{i_0, j_1} p_{j_1, i_1}\right) \left(\sum_{j_2 \in S} p_{i_1, j_2} p_{j_2, i_2}\right) \cdots \left(\sum_{j_n \in S} p_{i_{n-1}, j_n} p_{j_n, i_n}\right) \\
&= \lambda_{i_0} (P^2)_{i_0, i_1} (P^2)_{i_1, i_2} \cdots (P^2)_{i_{n-1}, i_n},
\end{aligned}
\]
where factoring the multiple sum of non-negative terms is justified by Tonelli's theorem (monotone convergence of finite partial sums). (When $n = 0$, the empty product is $1$ and $\mathbb{P}(W_0 = i_0) = \mathbb{P}(X_0 = i_0) = \lambda_{i_0}$.)

By the finite-dimensional distribution characterisation, $(W_n : n \ge 0)$ is a homogeneous Markov chain with initial distribution $\lambda$ and transition matrix $P^2$, whose $(i,j)$-entry is $(P^2)_{i,j} = \sum_{k \in S} p_{i,k} p_{k,j}$.

*(Equivalently, dividing the formula for $n+1$ by that for $n$ whenever $\mathbb{P}(W_0=i_0,\ldots,W_n=i_n)>0$ gives $\mathbb{P}(W_{n+1}=i_{n+1}\mid W_n=i_n,\ldots,W_0=i_0) = (P^2)_{i_n, i_{n+1}}$, directly verifying the Markov property and homogeneity.)*

**Finding $\mathbb{P}(W_1 = 0)$:**
Assuming $0 \in S$ (if $0 \notin S$, then $\mathbb{P}(W_1 = 0) = 0$), by the law of total probability (or $\mathbb{P}(W_1 = j) = (\lambda P^2)_j$),
\[
\mathbb{P}(W_1 = 0) = \mathbb{P}(X_2 = 0) = \sum_{i \in S} \lambda_i (P^2)_{i,0} = \sum_{i \in S} \sum_{k \in S} \lambda_i p_{i,k} p_{k,0}.
\]

### Part (b): $S = \{-1, 0, 1\}$, $p_{0,1} = p_{-1,-1} = 0$, $p_{-1,0} \ne p_{1,0}$, and $Y_n = |X_n|$

Since $S = \{-1, 0, 1\}$, the process $Y_n = |X_n|$ takes values in $\{0, 1\}$, with
\[
\{Y_m = 0\} = \{X_m = 0\}, \qquad \{Y_m = 1\} = \{X_m = -1\} \cup \{X_m = 1\}.
\]
The key effect of the given zero transition probabilities is:
- Because $p_{0,1} = 0$, from state $0$ the chain cannot jump to $+1$; thus any transition from $Y_{m-1} = 0$ to $Y_m = 1$ must go $0 \to -1$.
- Because $p_{-1,-1} = 0$, from state $-1$ the chain cannot stay at $-1$; thus any transition from $X_{m-1} = -1$ to $Y_m = 1$ must go $-1 \to +1$.

Let $\mu_k(0) = \mathbb{P}(X_k = 0)$ for $k \ge 0$.

#### (i) $\mathbb{P}(Y_{n+1} = 0 \mid Y_n = 1, Y_{n-1} = 0)$ (for $n \ge 1$)

Assume the conditioning event has positive probability. By the Markov property of $(X_k)$ and $p_{0,1} = 0$:
\[
\begin{aligned}
\mathbb{P}(Y_n = 1, Y_{n-1} = 0)
&= \mathbb{P}(X_n = -1, X_{n-1} = 0) + \mathbb{P}(X_n = 1, X_{n-1} = 0) \\
&= \mu_{n-1}(0)\, p_{0,-1} + \mu_{n-1}(0)\, p_{0,1} \\
&= \mu_{n-1}(0)\, p_{0,-1},
\end{aligned}
\]
so the conditioning event has positive probability if and only if $\mu_{n-1}(0) > 0$ and $p_{0,-1} > 0$.

Similarly, for the numerator:
\[
\begin{aligned}
\mathbb{P}(Y_{n+1} = 0, Y_n = 1, Y_{n-1} = 0)
&= \sum_{x \in \{-1, 1\}} \mathbb{P}(X_{n+1} = 0, X_n = x, X_{n-1} = 0) \\
&= \mu_{n-1}(0)\, p_{0,-1}\, p_{-1,0} + \mu_{n-1}(0)\, p_{0,1}\, p_{1,0} \\
&= \mu_{n-1}(0)\, p_{0,-1}\, p_{-1,0},
\end{aligned}
\]
since $p_{0,1} = 0$. Dividing gives:
\[
\mathbb{P}(Y_{n+1} = 0 \mid Y_n = 1, Y_{n-1} = 0) = \frac{\mu_{n-1}(0)\, p_{0,-1}\, p_{-1,0}}{\mu_{n-1}(0)\, p_{0,-1}} = p_{-1,0}.
\]

#### (ii) $\mathbb{P}(Y_{n+1} = 0 \mid Y_n = 1, Y_{n-1} = 1, Y_{n-2} = 0)$ (for $n \ge 2$)

Assume the conditioning event has positive probability. Expanding over $x, y \in \{-1, 1\}$ and using $p_{0,1} = 0$ (which forces $x = -1$) and $p_{-1,-1} = 0$ (which then forces $y = 1$):
\[
\begin{aligned}
\mathbb{P}(Y_n = 1, Y_{n-1} = 1, Y_{n-2} = 0)
&= \sum_{x \in \{-1,1\}} \sum_{y \in \{-1,1\}} \mathbb{P}(X_n = y, X_{n-1} = x, X_{n-2} = 0) \\
&= \mu_{n-2}(0) \sum_{x \in \{-1,1\}} \sum_{y \in \{-1,1\}} p_{0,x} p_{x,y} \\
&= \mu_{n-2}(0)\, p_{0,-1}\, p_{-1,1}.
\end{aligned}
\]
Thus the conditioning event has positive probability if and only if $\mu_{n-2}(0) > 0$, $p_{0,-1} > 0$, and $p_{-1,1} > 0$.

For the numerator, the exact same path $0 \to -1 \to 1 \to 0$ is the only term that can be non-zero:
\[
\begin{aligned}
\mathbb{P}(Y_{n+1} = 0, Y_n = 1, Y_{n-1} = 1, Y_{n-2} = 0)
&= \mu_{n-2}(0) \sum_{x \in \{-1,1\}} \sum_{y \in \{-1,1\}} p_{0,x} p_{x,y} p_{y,0} \\
&= \mu_{n-2}(0)\, p_{0,-1}\, p_{-1,1}\, p_{1,0}.
\end{aligned}
\]
Dividing gives:
\[
\mathbb{P}(Y_{n+1} = 0 \mid Y_n = 1, Y_{n-1} = 1, Y_{n-2} = 0) = \frac{\mu_{n-2}(0)\, p_{0,-1}\, p_{-1,1}\, p_{1,0}}{\mu_{n-2}(0)\, p_{0,-1}\, p_{-1,1}} = p_{1,0}.
\]

#### Conclusion on whether $(Y_n : n \ge 0)$ is a Markov chain

If $(Y_n : n \ge 0)$ were a homogeneous Markov chain, then for any conditioning histories ending in $Y_m = 1$ that have positive probability, the conditional probability of transitioning to $0$ at the next step would depend only on the current state $Y_m = 1$ (and not on the earlier values $Y_{m-1}, Y_{m-2}$ or the time index $m$). Specifically:
- Whenever both conditioning events in (i) and (ii) have positive probability — in particular, as soon as $p_{0,-1} > 0$, $p_{-1,1} > 0$, and $\mathbb{P}(X_k = 0) > 0$ for some $k \ge 0$ (which guarantees (i) is well-defined at $n = k+1$ with value $p_{-1,0}$, and (ii) is well-defined at $n = k+2$ with value $p_{1,0}$; and if $\mathbb{P}(X_{n-1}=0)>0$ and $\mathbb{P}(X_{n-2}=0)>0$ for the same $n \ge 2$, then both (i) and (ii) are well-defined at the same $n$, ruling out even an inhomogeneous Markov chain) — we have
  \[
  \mathbb{P}(Y_{n+1} = 0 \mid Y_n = 1, Y_{n-1} = 0) = p_{-1,0} \ne p_{1,0} = \mathbb{P}(Y_{n'+1} = 0 \mid Y_{n'} = 1, Y_{n'-1} = 1, Y_{n'-2} = 0).
  \]
- Therefore, **$(Y_n : n \ge 0)$ is not a (homogeneous) Markov chain** (under the non-degeneracy assumption that the conditioning events have positive probability).

*(Rigorous remark on degenerate edge cases:* If one of the positivity conditions fails so that the conditioning event in (ii) has probability $0$ for every $n \ge 2$, then $(Y_n : n \ge 0)$ **can** be a homogeneous Markov chain despite $p_{0,1} = p_{-1,-1} = 0$ and $p_{-1,0} \ne p_{1,0}$. For example, if $p_{-1,1} = 0$ (so $p_{-1,0} = 1$), $p_{0,-1} > 0$, $p_{1,0} \ne 1$, and $\lambda_1 = \mathbb{P}(X_0 = 1) = 0$, then $(X_n)$ never visits state $+1$, so $Y_n = -X_n$ is a bijection of $(X_n)$ and hence is a homogeneous Markov chain. Similarly, if $p_{0,-1} = 0$ and $\lambda_0 = 1$, then $Y_n \equiv 0$ is trivially Markov. Thus strictly speaking, $(Y_n)$ fails to be a homogeneous Markov chain whenever $p_{0,-1} > 0$, $p_{-1,1} > 0$, and $\mathbb{P}(X_k = 0) > 0$ for some $k \ge 0$.)

## Final Answers

- **(a)**: $(W_n : n \ge 0)$ is a homogeneous Markov chain with initial distribution $\lambda$ and transition matrix $P^2$, where $(P^2)_{i,j} = \sum_{k \in S} p_{i,k} p_{k,j}$. Moreover,
  \[
  \mathbb{P}(W_1 = 0) = \sum_{i \in S} \sum_{k \in S} \lambda_i p_{i,k} p_{k,0}.
  \]
- **(b)(i)**: $\mathbb{P}(Y_{n+1} = 0 \mid Y_n = 1, Y_{n-1} = 0) = p_{-1,0}$ (provided $\mathbb{P}(X_{n-1} = 0)\, p_{0,-1} > 0$).
- **(b)(ii)**: $\mathbb{P}(Y_{n+1} = 0 \mid Y_n = 1, Y_{n-1} = 1, Y_{n-2} = 0) = p_{1,0}$ (provided $\mathbb{P}(X_{n-2} = 0)\, p_{0,-1}\, p_{-1,1} > 0$).
- **Conclusion**: Since $p_{-1,0} \ne p_{1,0}$, $(Y_n : n \ge 0)$ is **not** a Markov chain whenever the conditioning events have positive probability (specifically, whenever $p_{0,-1} > 0$, $p_{-1,1} > 0$, and $\mathbb{P}(X_k = 0) > 0$ for some $k \ge 0$; in degenerate cases where one of these vanishes, $(Y_n)$ can be Markov).
