## Full Solution

### Preamble (Bookwork)

Let $P = (p_{ij})_{i,j \in I}$ be a transition (stochastic) matrix on a countable state space $I$, so $p_{ij} \ge 0$ for all $i,j \in I$ and $\sum_{j \in I} p_{ij} = 1$ for all $i \in I$. A **distribution** $\pi = (\pi_i)_{i \in I}$ on $I$ satisfies $\pi_i \ge 0$ for all $i \in I$ and $\sum_{i \in I} \pi_i = 1$.

1. **Invariant distribution:** A distribution $\pi$ is an *invariant distribution* for $P$ if $\pi P = \pi$, that is,
   \[
   \sum_{i \in I} \pi_i p_{ij} = \pi_j \qquad \text{for all } j \in I.
   \]
2. **Detailed balance:** A distribution $\pi$ and $P$ are in *detailed balance* if
   \[
   \pi_i p_{ij} = \pi_j p_{ji} \qquad \text{for all } i, j \in I.
   \]
3. **Proof that detailed balance implies invariance:** Suppose $\pi$ is a distribution in detailed balance with $P$. For every $j \in I$, summing over $i \in I$ (all terms are non-negative) gives
   \[
   (\pi P)_j = \sum_{i \in I} \pi_i p_{ij} = \sum_{i \in I} \pi_j p_{ji} = \pi_j \sum_{i \in I} p_{ji} = \pi_j \cdot 1 = \pi_j,
   \]
   since each row of the transition matrix $P$ sums to $1$. Thus $\pi P = \pi$, so $\pi$ is an invariant distribution.

### Part (a)

Suppose the Markov chain with transition matrix $P$ is **irreducible** and has an invariant distribution $\pi$. (Under irreducibility, the existence of an invariant distribution implies that the chain is positive recurrent, $\pi$ is the *unique* invariant distribution, and $\pi_i > 0$ for every $i \in I$. Note that irreducibility is essential: if $P$ has multiple disjoint closed classes, an invariant distribution is not unique and the identities below need not hold globally.)

Let $T_k = \inf\{n \ge 1 : X_n = k\}$ be the first return time to state $k$.

**(i)** Let $m_i = \mathbb{E}_i[T_i]$ be the expected return time to state $i$ starting from $i$. Then
\[
\pi_i = \frac{1}{m_i}, \qquad \text{equivalently } m_i = \frac{1}{\pi_i} \qquad \text{for all } i \in I.
\]

**(ii)** Let
\[
\gamma_i^k = \mathbb{E}_k\!\left[\sum_{n=0}^{T_k - 1} \mathbf{1}_{\{X_n = i\}}\right]
\]
be the expected time spent in state $i$ between visits to state $k$ (note that $\sum_{n=0}^{T_k - 1} \mathbf{1}_{\{X_n = i\}} = \sum_{n=1}^{T_k} \mathbf{1}_{\{X_n = i\}}$ under $\mathbb{P}_k$, and for $i \ne k$ this also equals $\sum_{n=1}^{T_k - 1} \mathbf{1}_{\{X_n = i\}}$). Then $\gamma^k = (\gamma_i^k)_{i \in I}$ is the unique invariant measure with $\gamma_k^k = 1$, and
\[
\gamma_i^k = \frac{\pi_i}{\pi_k} \qquad \text{for all } i, k \in I
\]
(equivalently, $\pi_i = \pi_k \gamma_i^k = \gamma_i^k / m_k$).

### Part (b)

Here $I = \{0, 1, 2, \ldots\}$, $q \ge 2$, $p \in (0, 1]$, and the non-zero transition probabilities are $p_{01} = p$, $p_{00} = 1 - p$, and for $i \ge 1$:
\[
p_{i, i+1} = q^{-(i+2)}, \qquad p_{i, i-1} = q^{-i}, \qquad p_{i, i} = 1 - q^{-(i+2)} - q^{-i},
\]
with $p_{ij} = 0$ whenever $|i - j| > 1$.

**Verification of hypotheses (stochasticity, irreducibility, invariant distribution):**
- *Valid stochastic matrix:* For $i = 0$, $p \in (0, 1]$ gives $p_{01} > 0$, $p_{00} \ge 0$, and $p_{00} + p_{01} = 1$. For $i \ge 1$, since $q \ge 2$, $p_{i, i+1} > 0$, $p_{i, i-1} > 0$, and
  \[
  q^{-(i+2)} + q^{-i} = q^{-i}(1 + q^{-2}) \le \frac{1}{2}\!\left(1 + \frac{1}{4}\right) = \frac{5}{8} < 1,
  \]
  so $p_{ii} \ge \frac{3}{8} > 0$ and each row sums to $1$.
- *Irreducibility:* Since $p_{01} = p > 0$, $p_{i, i+1} = q^{-(i+2)} > 0$, and $p_{i, i-1} = q^{-i} > 0$ for all $i \ge 1$, every state communicates with its neighbours, and hence by transitivity $i \leftrightarrow j$ for all $i, j \in I$. Thus the chain is **irreducible**.
- *Invariant distribution via detailed balance:* Since $p_{ij} = 0$ for $|i - j| > 1$, the detailed balance equations $\pi_i p_{ij} = \pi_j p_{ji}$ reduce to
  \[
  \pi_i p_{i, i+1} = \pi_{i+1} p_{i+1, i} \qquad \text{for all } i \ge 0.
  \]
  - For $i = 0$: $\pi_0 p = \pi_1 q^{-1}$, so
    \[
    \pi_0 = \frac{1}{pq}\,\pi_1.
    \]
  - For $i \ge 1$: $\pi_i q^{-(i+2)} = \pi_{i+1} q^{-(i+1)}$, so
    \[
    \pi_{i+1} = \frac{q^{-(i+2)}}{q^{-(i+1)}}\,\pi_i = q^{-1}\pi_i.
    \]
    By induction on $i \ge 1$,
    \[
    \pi_i = q^{-(i-1)}\pi_1 \qquad \text{for all } i \ge 1.
    \]
  Check normalisability: since $q \ge 2$, we have $0 < q^{-1} \le \frac{1}{2} < 1$, so the geometric series converges:
  \[
  \sum_{i=0}^{\infty} \pi_i
  = \pi_0 + \sum_{i=1}^{\infty} \pi_i
  = \pi_1 \!\left(\frac{1}{pq} + \sum_{i=1}^{\infty} q^{-(i-1)}\right)
  = \pi_1 \!\left(\frac{1}{pq} + \frac{1}{1 - q^{-1}}\right)
  = \pi_1 \!\left(\frac{1}{pq} + \frac{q}{q - 1}\right)
  = \pi_1 \frac{pq^2 + q - 1}{pq(q - 1)}.
  \]
  Since $p > 0$ and $q \ge 2$, $pq^2 + q - 1 > 0$. Normalising $\sum_{i=0}^{\infty} \pi_i = 1$ gives the distribution
  \[
  \pi_1 = \frac{pq(q - 1)}{pq^2 + q - 1}, \qquad
  \pi_0 = \frac{q - 1}{pq^2 + q - 1}, \qquad
  \pi_i = \frac{pq(q - 1)}{pq^2 + q - 1}\,q^{-(i-1)} \quad (i \ge 1).
  \]
  By the preamble, $\pi$ is an invariant distribution for $P$. Because the chain is irreducible, $\pi$ is the *unique* invariant distribution and the chain is positive recurrent, so the results of part (a) apply.

#### (b)(i) Expected time spent in $\{2, 4, 6, \ldots\}$ between visits to state $1$

Let $E = \{2, 4, 6, \ldots\}$ and $T_1 = \inf\{n \ge 1 : X_n = 1\}$. The expected time spent in $E$ between visits to state $1$ is
\[
\mathbb{E}_1\!\left[\sum_{n=0}^{T_1 - 1} \mathbf{1}_{\{X_n \in E\}}\right]
= \mathbb{E}_1\!\left[\sum_{m=1}^{\infty} \sum_{n=0}^{T_1 - 1} \mathbf{1}_{\{X_n = 2m\}}\right]
= \sum_{m=1}^{\infty} \mathbb{E}_1\!\left[\sum_{n=0}^{T_1 - 1} \mathbf{1}_{\{X_n = 2m\}}\right]
= \sum_{m=1}^{\infty} \gamma_{2m}^1,
\]
where the interchange of expectation and infinite sum is justified by the Monotone Convergence Theorem (Tonelli's theorem), as all summands are non-negative.

By part (a)(ii), for every $m \ge 1$,
\[
\gamma_{2m}^1 = \frac{\pi_{2m}}{\pi_1} = q^{-(2m - 1)}.
\]
Since $0 < q^{-2} \le \frac{1}{4} < 1$, this geometric series sums to
\[
\sum_{m=1}^{\infty} q^{-(2m - 1)} = \frac{q^{-1}}{1 - q^{-2}} = \frac{q}{q^2 - 1}.
\]
*(Notice this is independent of $p$: excursions from $1$ to $0$ must return to $1$ before reaching any state in $\{2, 4, 6, \ldots\}$.)*

---

#### (b)(ii) Expected time taken to return to state $1$, starting from $1$

By part (a)(i), the expected return time $m_1 = \mathbb{E}_1[T_1]$ to state $1$ is
\[
m_1 = \frac{1}{\pi_1} = \frac{1}{pq} + \frac{q}{q - 1} = \frac{pq^2 + q - 1}{pq(q - 1)}.
\]

---

#### (b)(iii) Expected time taken to hit state $0$ starting from $1$

Let $H_0 = \inf\{n \ge 0 : X_n = 0\}$ and $k_i = \mathbb{E}_i[H_0]$ for $i \ge 0$. We want $k_1 = \mathbb{E}_1[H_0]$.

Consider the first return time $T_0 = \inf\{n \ge 1 : X_n = 0\}$ starting from $X_0 = 0$. Conditioning on the first step $X_1 \in \{0, 1\}$:
- If $X_1 = 0$ (probability $p_{00} = 1 - p$), then $T_0 = 1$.
- If $X_1 = 1$ (probability $p_{01} = p > 0$), then $T_0 = 1 + \inf\{m \ge 0 : X_{1+m} = 0\}$. By the Markov property at time $1$, conditional on $X_1 = 1$ the shifted chain $(X_{1+m})_{m \ge 0}$ has the same distribution as $(X_m)_{m \ge 0}$ under $\mathbb{P}_1$, so $\mathbb{E}_0[T_0 \mid X_1 = 1] = 1 + \mathbb{E}_1[H_0] = 1 + k_1$.

Therefore, in $[0, \infty]$,
\[
m_0 = \mathbb{E}_0[T_0] = (1 - p)\cdot 1 + p(1 + k_1) = 1 + p k_1.
\]
On the other hand, by part (a)(i),
\[
m_0 = \frac{1}{\pi_0} = \frac{pq^2 + q - 1}{q - 1} = 1 + \frac{pq^2}{q - 1} < \infty.
\]
Since $p \in (0, 1]$ is strictly positive, subtracting $1$ and dividing by $p$ gives
\[
k_1 = \frac{m_0 - 1}{p} = \frac{q^2}{q - 1}.
\]

*(Independent check via minimal non-negative solution of hitting-time equations: $(k_i)_{i \ge 0}$ is the minimal non-negative solution to $k_0 = 0$ and $k_i = 1 + q^{-i}k_{i-1} + (1 - q^{-i} - q^{-(i+2)})k_i + q^{-(i+2)}k_{i+1}$ for $i \ge 1$. Writing $d_i = k_i - k_{i-1}$ gives $d_i - q^{-2}d_{i+1} = q^i$, whose general solution is $d_i = \frac{q^{i+1}}{q-1} + C q^{2(i-1)}$. If $C < 0$, then since $q \ge 2$, $d_i \to -\infty$ and hence $k_i = \sum_{m=1}^i d_m \to -\infty < 0$, impossible for a non-negative solution. Thus $C \ge 0$, and the minimal non-negative solution has $C = 0$, giving $k_i = \frac{q^2(q^i - 1)}{(q - 1)^2}$ and in particular $k_1 = d_1 = \frac{q^2}{q - 1}$.)*
