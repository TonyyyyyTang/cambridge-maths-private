## Full Solution

Let $P$ be the transition matrix of the discrete-time homogeneous Markov chain $(X_n)_{n \ge 0}$ on a countable state space $I$, started at $X_0 = i$, and write $\mathbb{P}_i(\cdot)$ for probability under $X_0 = i$.

### Step 1: Successive visit times and double-sum identity

Define inductively the successive times of visits to state $i$:
\[
T_i^{(0)} = 0, \qquad
T_i^{(1)} = \inf\{n \ge 1 : X_n = i\}, \qquad
T_i^{(r+1)} = \inf\{n > T_i^{(r)} : X_n = i\} \quad (r \ge 1),
\]
with the standard convention $\inf \emptyset = +\infty$ (so if $T_i^{(r)} = +\infty$, then $\{n > T_i^{(r)} : X_n = i\} = \emptyset$ and hence $T_i^{(r+1)} = +\infty$).

Under $\mathbb{P}_i$, we have $X_0 = i$, so $0 \in S := \{n \in \mathbb{N}_0 : X_n = i\}$. By a straightforward induction on $r \ge 0$, $T_i^{(r)}$ is the $(r+1)$-th smallest element of $S$ if $|S| \ge r+1$, and $T_i^{(r)} = +\infty$ if $|S| \le r$. In particular, the finite terms among $T_i^{(0)}, T_i^{(1)}, T_i^{(2)}, \dots$ are strictly increasing and enumerate $S$ bijectively. Consequently, for every fixed integer $n \ge 0$,
\[
\{X_n = i\} = \bigsqcup_{r=0}^\infty \{T_i^{(r)} = n\}
\]
is a disjoint union (in fact $\{T_i^{(r)} = n\} = \emptyset$ for $r > n$, since $T_i^{(r)} \ge r$). By countable additivity of $\mathbb{P}_i$,
\[
\mathbb{P}_i(X_n = i) = \sum_{r=0}^\infty \mathbb{P}_i(T_i^{(r)} = n) \qquad \text{for every } n \ge 0.
\]
Summing over all $n \ge 0$ and noting that every term $\mathbb{P}_i(T_i^{(r)} = n) \ge 0$, we may interchange the order of summation (Tonelli's theorem for non-negative double series: both iterated sums equal $\sup_{M,R} \sum_{n=0}^M \sum_{r=0}^R \mathbb{P}_i(T_i^{(r)} = n) \in [0, +\infty]$):
\[
\sum_{n=0}^\infty \mathbb{P}_i(X_n = i)
= \sum_{n=0}^\infty \sum_{r=0}^\infty \mathbb{P}_i(T_i^{(r)} = n)
= \sum_{r=0}^\infty \sum_{n=0}^\infty \mathbb{P}_i(T_i^{(r)} = n)
= \sum_{r=0}^\infty \mathbb{P}_i(T_i^{(r)} < \infty),
\]
where the last equality uses countable additivity for the disjoint union $\{T_i^{(r)} < \infty\} = \bigsqcup_{n=0}^\infty \{T_i^{(r)} = n\}$.

*(Remark: Equivalently, setting $V_i = \sum_{n=0}^\infty \mathbf{1}_{\{X_n = i\}}$, we have $\{V_i \ge r+1\} = \{T_i^{(r)} < \infty\}$ and $\mathbb{E}_i[V_i] = \sum_{n=0}^\infty \mathbb{P}_i(X_n = i) = \sum_{r=0}^\infty \mathbb{P}_i(V_i \ge r+1)$.)*

### Step 2: Verification that $T_i^{(r)}$ is a stopping time

For $r = 0$, $\{T_i^{(0)} = 0\} = \{X_0 = i\}$ (the whole space under $\mathbb{P}_i$) and $\{T_i^{(0)} = n\} = \emptyset$ for $n \ge 1$. For any $r \ge 1$ and $n \ge 0$, $T_i^{(r)}$ is the $r$-th positive time at which the chain visits $i$, so
\[
\{T_i^{(r)} = n\} = \begin{cases}
\emptyset & \text{if } n < r, \\
\left\{X_n = i \text{ and } \sum_{m=1}^{n-1} \mathbf{1}_{\{X_m = i\}} = r - 1\right\} & \text{if } n \ge r.
\end{cases}
\]
In every case, $\{T_i^{(r)} = n\}$ is determined completely by $(X_0, X_1, \dots, X_n)$. Hence each $T_i^{(r)}$ ($r \ge 0$) is a stopping time with respect to $(X_n)_{n \ge 0}$.

### Step 3: Computation of $\mathbb{P}_i(T_i^{(r)} < \infty)$ via the strong Markov property

Let
\[
f_i := \mathbb{P}_i(T_i^{(1)} < \infty) \in [0, 1]
\]
be the return probability to state $i$.

For $r = 0$, $T_i^{(0)} = 0 < \infty$ everywhere, so $\mathbb{P}_i(T_i^{(0)} < \infty) = 1$.

We prove by induction on $r \ge 1$ that
\[
\mathbb{P}_i(T_i^{(r)} < \infty) = f_i^r \qquad \text{for all } r \ge 1.
\]
- **Base case ($r = 1$):** Immediate from the definition $f_i = \mathbb{P}_i(T_i^{(1)} < \infty)$.
- **Inductive step:** Assume $\mathbb{P}_i(T_i^{(r)} < \infty) = f_i^r$ for some $r \ge 1$. Since $T_i^{(r+1)} > T_i^{(r)}$ whenever $T_i^{(r)} < \infty$ and $T_i^{(r+1)} = +\infty$ whenever $T_i^{(r)} = +\infty$, we have the inclusion $\{T_i^{(r+1)} < \infty\} \subseteq \{T_i^{(r)} < \infty\}$.
  - **Case 1: $\mathbb{P}_i(T_i^{(r)} < \infty) = 0$.** By monotonicity of probability, $0 \le \mathbb{P}_i(T_i^{(r+1)} < \infty) \le \mathbb{P}_i(T_i^{(r)} < \infty) = 0$. By the inductive hypothesis, $f_i^r = 0$, so $f_i = 0$ and hence $f_i^{r+1} = 0 = \mathbb{P}_i(T_i^{(r+1)} < \infty)$.
  - **Case 2: $\mathbb{P}_i(T_i^{(r)} < \infty) > 0$.** On the event $\{T_i^{(r)} < \infty\}$, we automatically have $X_{T_i^{(r)}} = i$ by definition of $T_i^{(r)}$. Thus $\{T_i^{(r)} < \infty\} = \{T_i^{(r)} < \infty,\, X_{T_i^{(r)}} = i\}$ has strictly positive probability. By the strong Markov property applied to the stopping time $T_i^{(r)}$, conditional on $\{T_i^{(r)} < \infty\}$, the shifted process
    \[
    Y_m := X_{T_i^{(r)} + m}, \qquad m \ge 0,
    \]
    is a Markov chain with the same transition matrix $P$ and initial state $Y_0 = i$ (and is independent of $X_0, X_1, \dots, X_{T_i^{(r)}}$). On $\{T_i^{(r)} < \infty\}$,
    \[
    T_i^{(r+1)} < \infty \iff \exists\, n > T_i^{(r)} \text{ with } X_n = i \iff \exists\, m \ge 1 \text{ with } Y_m = i.
    \]
    Hence
    \[
    \mathbb{P}_i(T_i^{(r+1)} < \infty \mid T_i^{(r)} < \infty)
    = \mathbb{P}_i(\exists\, m \ge 1 : Y_m = i \mid T_i^{(r)} < \infty)
    = \mathbb{P}_i(\exists\, m \ge 1 : X_m = i)
    = \mathbb{P}_i(T_i^{(1)} < \infty)
    = f_i.
    \]
    Using $\{T_i^{(r+1)} < \infty\} \subseteq \{T_i^{(r)} < \infty\}$ and the inductive hypothesis,
    \[
    \mathbb{P}_i(T_i^{(r+1)} < \infty)
    = \mathbb{P}_i(T_i^{(r+1)} < \infty \mid T_i^{(r)} < \infty)\,\mathbb{P}_i(T_i^{(r)} < \infty)
    = f_i \cdot f_i^r
    = f_i^{r+1}.
    \]

This completes the induction.

### Step 4: Summing the geometric series and conclusion

Substituting Step 3 into Step 1 gives
\[
\sum_{n=0}^\infty \mathbb{P}_i(X_n = i) = 1 + \sum_{r=1}^\infty f_i^r.
\]
Observe that the event $\{X_n \ne i \text{ for all } n \ge 1\}$ is precisely the complement of $\{T_i^{(1)} < \infty\}$:
\[
\mathbb{P}_i(X_n \ne i \text{ for all } n \ge 1)
= \mathbb{P}_i(T_i^{(1)} = \infty)
= 1 - \mathbb{P}_i(T_i^{(1)} < \infty)
= 1 - f_i.
\]
Now consider all values of $f_i \in [0, 1]$:
- If $0 \le f_i < 1$ (including the degenerate case $f_i = 0$, where $1 + \sum_{r=1}^\infty 0^r = 1 = \frac{1}{1-0}$), the geometric series converges to
  \[
  1 + \sum_{r=1}^\infty f_i^r = \frac{1}{1 - f_i} = \frac{1}{\mathbb{P}_i(X_n \ne i \text{ for all } n \ge 1)}.
  \]
- If $f_i = 1$, then $1 + \sum_{r=1}^\infty 1 = +\infty$, while $\mathbb{P}_i(X_n \ne i \text{ for all } n \ge 1) = 1 - 1 = 0$, so using the convention $1/0 = +\infty$,
  \[
  \sum_{n=0}^\infty \mathbb{P}_i(X_n = i) = +\infty = \frac{1}{0} = \frac{1}{\mathbb{P}_i(X_n \ne i \text{ for all } n \ge 1)}.
  \]

In all cases, the claimed identity holds. $\square$

## Final Answers

Proof question. Established for every Markov chain $(X_n)_{n \ge 0}$ with $X_0 = i$ (covering $f_i = 0$, $0 < f_i < 1$, and $f_i = 1$ with $1/0 = +\infty$) that
\[
\sum_{n=0}^\infty \mathbb{P}_i(X_n = i) = 1 + \sum_{r=1}^\infty f_i^r = \frac{1}{1 - f_i} = \frac{1}{\mathbb{P}_i(X_n \ne i \text{ for all } n \ge 1)},
\]
where $f_i = \mathbb{P}_i(T_i^{(1)} < \infty)$.

## Confidence & Edge-Case Notes

- **Confidence:** `high`.
- **Key edge cases & pitfalls to watch in Phase B:**
  1. **Conditioning on probability-zero events ($f_i = 0$):** Many proofs blindly write $\mathbb{P}_i(T_i^{(r+1)} < \infty \mid T_i^{(r)} < \infty) = f_i$ without checking $\mathbb{P}_i(T_i^{(r)} < \infty) > 0$. Explicitly splitting off $\mathbb{P}_i(T_i^{(r)} < \infty) = 0$ (and starting the induction at $r = 1$ to avoid the $0^0$ ambiguity) makes the proof completely airtight.
  2. **Stopping-time verification:** A Tripos-standard proof should verify explicitly that $T_i^{(r)}$ is a stopping time and that $X_{T_i^{(r)}} = i$ on $\{T_i^{(r)} < \infty\}$ before invoking the strong Markov property.
  3. **Interchange of sum and expectation / infinite values:** When $f_i = 1$, $\mathbb{E}_i[V_i] = +\infty$, so any proof using $\mathbb{E}_i[V_i]$ must justify interchanging expectation and infinite sum for non-negative random variables (e.g., Monotone Convergence Theorem) and not assume $\mathbb{E}_i[V_i] < \infty$; the disjoint decomposition + Tonelli for non-negative double series avoids extended-real expectations altogether.
  4. **Indexing convention ($n \ge 0$ vs $n \ge 1$):** Because the sum starts at $n = 0$ ($\mathbb{P}_i(X_0 = i) = 1$), the result is $\frac{1}{1 - f_i}$, not $\frac{f_i}{1 - f_i}$.
