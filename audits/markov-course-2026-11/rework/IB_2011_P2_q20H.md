### Part (i)

Let $Z = \prod_{n=0}^{H-1} g(X_n)$, where $H = \inf\{n \geqslant 0 : X_n \in A\}$ (with the standard convention $\inf \emptyset = \infty$).

First note that $Z$ is well-defined and takes values in $[0, 1]$ on every sample path, including on $\{H = \infty\}$: because $0 < g(k) \leqslant 1$ for all $k \in S$, the partial products $M_m = \prod_{n=0}^{m-1} g(X_n)$ are non-increasing in $(0, 1]$ as $m$ increases, so when $H = \infty$ the infinite product
$$\prod_{n=0}^{\infty} g(X_n) := \lim_{m \to \infty} \prod_{n=0}^{m-1} g(X_n)$$
exists and lies in $[0, 1]$. Hence $Z \in [0, 1]$ is bounded, so $V_i = \mathbb{E}[Z \mid X_0 = i] \in [0, 1]$ exists and is finite for all $i \in S$.

We now consider the two cases:
- **Case 1: $i \in A$.** Given $X_0 = i \in A$, we have $H = 0$, so by the convention $\prod_{n=0}^{-1} a_n = 1$, $Z = 1$ surely, and hence
  $$V_i = \mathbb{E}[1 \mid X_0 = i] = 1.$$
- **Case 2: $i \notin A$.** Given $X_0 = i \notin A$, we have $H \geqslant 1$ (possibly $H = \infty$). Define the shifted process $\tilde{X}_m = X_{m+1}$ ($m \geqslant 0$) and its hitting time $\tilde{H} = \inf\{m \geqslant 0 : \tilde{X}_m \in A\}$, so $H = 1 + \tilde{H}$ (with $1 + \infty = \infty$). We verify that
  $$Z = \prod_{n=0}^{H-1} g(X_n) = g(X_0) \prod_{m=0}^{\tilde{H}-1} g(\tilde{X}_m)$$
  in all subcases:
  - if $H = 1$ ($\tilde{H} = 0$), both sides equal $g(X_0)$ (using the empty product convention $\prod_{m=0}^{-1} = 1$);
  - if $2 \leqslant H < \infty$, re-indexing $m = n - 1$ gives $\prod_{n=0}^{H-1} g(X_n) = g(X_0)\prod_{m=0}^{\tilde{H}-1} g(\tilde{X}_m)$;
  - if $H = \infty$ ($\tilde{H} = \infty$), $\prod_{n=0}^M g(X_n) = g(X_0)\prod_{m=0}^{M-1} g(\tilde{X}_m)$ for all $M \geqslant 1$, and taking $M \to \infty$ preserves equality.

  Partitioning by the finite state space $S$ according to the value of $X_1$ and applying the Markov property at time $1$ (conditional on $X_1 = j$, the shifted process $(\tilde{X}_m)_{m \geqslant 0}$ is independent of $X_0$ and has the law of the Markov chain started from $j$):
  $$\begin{aligned}
  V_i &= \mathbb{E}[Z \mid X_0 = i] \\
      &= \sum_{j \in S} \mathbb{P}(X_1 = j \mid X_0 = i)\,\mathbb{E}\left[g(X_0)\prod_{m=0}^{\tilde{H}-1} g(\tilde{X}_m) \;\middle|\; X_0 = i, X_1 = j\right] \\
      &= \sum_{j \in S} P_{ij}\, g(i)\,\mathbb{E}\left[\prod_{m=0}^{\tilde{H}-1} g(\tilde{X}_m) \;\middle|\; \tilde{X}_0 = j\right] \\
      &= g(i)\sum_{j \in S} P_{ij} V_j
  \end{aligned}$$
  (with any term having $P_{ij} = 0$ omitted / contributing $0$).

Combining both cases yields
$$V_i = \begin{cases} 1 & \text{if } i \in A, \\ g(i)\sum_{j \in S} P_{ij} V_j & \text{otherwise.} \end{cases}$$

### Part (ii)

The state space is $S = \{1, 2, \ldots, N\}$ (with $N \geqslant 1$). From vertex $i > 1$, the flea jumps uniformly to $\{1, \ldots, i-1\}$; upon reaching vertex $1$, the flea dies, so vertex $1$ is an absorbing state. Thus the transition probabilities $P_{ij} = \mathbb{P}(X_{n+1} = j \mid X_n = i)$ for $i, j \in \{1, \ldots, N\}$ are:
- for $i = 1$:
  $$P_{1j} = \delta_{1j} = \begin{cases} 1 & \text{if } j = 1, \\ 0 & \text{if } 2 \leqslant j \leqslant N; \end{cases}$$
- for $2 \leqslant i \leqslant N$:
  $$P_{ij} = \begin{cases} \dfrac{1}{i - 1} & \text{if } 1 \leqslant j \leqslant i - 1, \\[6pt] 0 & \text{if } i \leqslant j \leqslant N. \end{cases}$$
(Note that every row sums to $1$ and all entries are non-negative.)

### Part (iii)

The flea is alive on days $0, 1, \ldots, H - 1$ and dies on day $H = \inf\{n \geqslant 0 : X_n = 1\}$ upon reaching vertex $1$. Notice that from $X_0 = i$, the chain strictly decreases its vertex label at every step until hitting $1$, so $H \leqslant i - 1 < \infty$ surely.

Fix $s \in (0, 1]$, and apply part (i) with $A = \{1\}$ and the constant function $g(k) = s$ for all $k \in S$. The hypothesis $0 < g(k) \leqslant 1$ is satisfied since $0 < s \leqslant 1$. Because $H < \infty$ surely,
$$\prod_{n=0}^{H-1} g(X_n) = \prod_{n=0}^{H-1} s = s^H$$
(including when $H = 0$, where the empty product is $1 = s^0$), so $V_i = \mathbb{E}(s^H \mid X_0 = i)$ coincides with the quantity in part (i).

Part (i) immediately gives:
1. For $i = 1 \in A$:
   $$V_1 = 1.$$
2. For $2 \leqslant k \leqslant N$ ($k \notin A$):
   $$V_k = s \sum_{j=1}^N P_{kj} V_j = \frac{s}{k - 1} \sum_{j=1}^{k-1} V_j.$$
   Since $s > 0$, multiplying by $(k - 1)/s$ yields
   $$\frac{k - 1}{s} V_k = \sum_{j=1}^{k-1} V_j \qquad (2 \leqslant k \leqslant N). \tag{$\dagger$}$$
   Observe that $(\dagger)$ also holds trivially for $k = 1$, where both sides equal $0$ (interpreting the empty sum $\sum_{j=1}^0 V_j = 0$).

Now let $1 \leqslant i \leqslant N - 1$ (so $k = i + 1 \in \{2, \ldots, N\}$). Applying $(\dagger)$ at $k = i + 1$ and splitting off the $j = i$ term, then substituting $(\dagger)$ at $k = i$:
$$\frac{i}{s} V_{i+1} = \sum_{j=1}^i V_j = V_i + \sum_{j=1}^{i-1} V_j = V_i + \frac{i - 1}{s} V_i.$$
*(Remark: in the chain on $\{1, \ldots, N\}$, this holds for $1 \leqslant i \leqslant N - 1$; equivalently, since the law of $H$ from $X_0 = i$ does not depend on $N \geqslant i$, it holds for all $i \geqslant 1$.)*

Multiplying both sides by $s / i$ (valid since $i \geqslant 1$ and $s > 0$):
$$V_{i+1} = \frac{s + i - 1}{i} V_i = \left(1 + \frac{s - 1}{i}\right) V_i \qquad (1 \leqslant i \leqslant N - 1).$$
By induction on $k = 1, \ldots, N$, starting from $V_1 = 1$, we obtain
$$V_k = \prod_{i=1}^{k-1} \left(1 + \frac{s - 1}{i}\right) \qquad (1 \leqslant k \leqslant N),$$
and setting $k = N$ gives
$$\mathbb{E}(s^H \mid X_0 = N) = V_N = \prod_{i=1}^{N-1} \left(1 + \frac{s - 1}{i}\right)$$
(which also holds for $N = 1$, where $H = 0$ surely and the empty product is $1$).

### Part (iv)

Given $X_0 = N$, the random variable $H$ takes values in the **finite** set $\{0, 1, \ldots, N - 1\}$ (since $X_n$ strictly decreases before reaching $1$). Therefore its probability generating function
$$G(s) := \mathbb{E}(s^H \mid X_0 = N) = \sum_{k=0}^{N-1} \mathbb{P}(H = k \mid X_0 = N)\, s^k$$
is a **finite polynomial** in $s$, hence differentiable on all of $\mathbb{R}$ (with no convergence subtleties at $s = 1$), and its derivative at $s = 1$ (equivalently its left-hand derivative $G'_-(1)$) is
$$G'(1) = \sum_{k=1}^{N-1} k\,\mathbb{P}(H = k \mid X_0 = N) = \mathbb{E}(H \mid X_0 = N).$$

On the other hand, by part (iii), for all $s \in (0, 1]$,
$$G(s) = \prod_{i=1}^{N-1} \left(1 + \frac{s - 1}{i}\right).$$
- If $N = 1$, then $G(s) = 1$, so $\mathbb{E}(H \mid X_0 = 1) = G'_-(1) = 0 = \sum_{i=1}^0 \frac{1}{i}$.
- If $N \geqslant 2$, differentiating the finite product on $(0, 1]$ by the product rule (taking the left-hand derivative at $s = 1$) gives
  $$G'(s) = \sum_{i=1}^{N-1} \frac{1}{i} \prod_{\substack{j=1 \\ j \neq i}}^{N-1} \left(1 + \frac{s - 1}{j}\right).$$
  Evaluating at $s = 1$, every factor $1 + \frac{1 - 1}{j}$ equals $1$, so
  $$\mathbb{E}(H \mid X_0 = N) = G'_-(1) = \sum_{i=1}^{N-1} \frac{1}{i}.$$

*(Alternatively, on $(0, 1]$ each factor $1 + (s-1)/i = (i - 1 + s)/i > 0$, so logarithmic differentiation gives $\frac{G'(s)}{G(s)} = \sum_{i=1}^{N-1} \frac{1/i}{1 + (s-1)/i}$; letting $s \uparrow 1$ with $G(1) = 1$ gives $G'_-(1) = \sum_{i=1}^{N-1} \frac{1}{i}$.)*

## Final Answers

- **(i)** $V_i = 1$ if $i \in A$, and $V_i = g(i)\sum_{j \in S} P_{ij} V_j$ if $i \notin A$.
- **(ii)** On state space $\{1, \ldots, N\}$: $P_{11} = 1$, $P_{1j} = 0$ ($j > 1$); and for $2 \leqslant i \leqslant N$, $P_{ij} = \frac{1}{i-1}$ for $1 \leqslant j \leqslant i - 1$ and $P_{ij} = 0$ for $i \leqslant j \leqslant N$.
- **(iii)** $V_1 = 1$, $\frac{i}{s}V_{i+1} = V_i + \frac{i-1}{s}V_i$ ($1 \leqslant i \leqslant N - 1$), and $\mathbb{E}(s^H \mid X_0 = N) = \prod_{i=1}^{N-1}\left(1 + \frac{s - 1}{i}\right)$.
- **(iv)** $\mathbb{E}(H \mid X_0 = N) = \sum_{i=1}^{N-1} \frac{1}{i}$.

  3. **Base case $i = 1$ in the recurrence of part (iii):** When deducing $\frac{i}{s}V_{i+1} = V_i + \frac{i-1}{s}V_i$ from $\frac{k-1}{s}V_k = \sum_{j=1}^{k-1}V_j$, the identity for $k = i$ originally came from $k \geqslant 2$, so one should check $i = 1$ separately ($\frac{1}{s}V_2 = V_1 = V_1 + \frac{0}{s}V_1$).
