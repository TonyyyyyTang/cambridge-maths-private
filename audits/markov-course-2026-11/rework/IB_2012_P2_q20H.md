### Assumptions for Parts (i) and (ii)

For the symmetric random walk to be well-defined and possess an invariant **distribution** $\pi$, we take the connected graph $G = (V, E)$ to be a **finite**, connected, simple (undirected, loopless, no multiple edges) graph with $|V| \geqslant 2$ (so every vertex $i \in V$ has degree $d_i = \deg(i) \geqslant 1$ and $\sum_{k \in V} d_k = 2|E| \in [2, \infty)$). Its transition matrix $P = (P_{ij})_{i,j \in V}$ is
$$P_{ij} = \begin{cases} \dfrac{1}{d_i} & \text{if } \{i, j\} \in E \text{ (written } i \sim j\text{)}, \\[6pt] 0 & \text{otherwise.} \end{cases}$$

### Part (i): The Invariant Distribution $\pi$ Satisfies Detailed Balance

**Theorems used:**
1. *Existence and uniqueness of invariant distribution:* Every finite, irreducible Markov chain is positive-recurrent and has a **unique** invariant distribution $\pi$ (satisfying $\pi_i > 0$, $\sum_{i \in V} \pi_i = 1$, and $\pi P = \pi$).
2. *Detailed balance implies invariance:* If a probability distribution $\pi$ satisfies the detailed balance equations $\pi_i P_{ij} = \pi_j P_{ji}$ for all $i, j \in V$, then $\pi$ is an invariant distribution for $P$. (Proof: $(\pi P)_j = \sum_{i \in V} \pi_i P_{ij} = \sum_{i \in V} \pi_j P_{ji} = \pi_j \sum_{i \in V} P_{ji} = \pi_j$.)

**Proof:**
Since $G$ is connected, for any $i, j \in V$ there exists a finite path $i = v_0, v_1, \ldots, v_r = j$ in $G$, whence $P_{ij}^{(r)} \geqslant \prod_{t=0}^{r-1} \frac{1}{d_{v_t}} > 0$. Thus $(X_n)$ is **irreducible**. Because $V$ is finite, Theorem 1 guarantees a **unique** invariant distribution.

Define $\pi = (\pi_i)_{i \in V}$ by
$$\pi_i = \frac{d_i}{2|E|} = \frac{d_i}{\sum_{k \in V} d_k} \qquad (i \in V).$$
Clearly $\pi_i > 0$ for all $i \in V$ and $\sum_{i \in V} \pi_i = \frac{\sum_{i \in V} d_i}{2|E|} = 1$ (by the handshaking lemma), so $\pi$ is a probability distribution. Checking detailed balance for any $i, j \in V$:
- If $i \sim j$, then
  $$\pi_i P_{ij} = \frac{d_i}{2|E|} \cdot \frac{1}{d_i} = \frac{1}{2|E|} = \frac{d_j}{2|E|} \cdot \frac{1}{d_j} = \pi_j P_{ji}.$$
- If $i \not\sim j$, then $P_{ij} = 0 = P_{ji}$, so $\pi_i P_{ij} = 0 = \pi_j P_{ji}$.

By Theorem 2, $\pi$ is an invariant distribution for $P$. By uniqueness of the invariant distribution (Theorem 1), this $\pi$ is **the** invariant distribution of $(X_n)$, and it satisfies detailed balance.

### Part (ii): Reversibility Implies $\pi_i q_{ij} = \pi_j q_{ji}$

**Theorem used (Time-Reversal / Reversibility Theorem):**
If $(X_n)_{n \geqslant 0}$ is a Markov chain with transition matrix $P$ and invariant distribution $\pi$ in detailed balance, and $X_0 \sim \pi$, then $(X_n)$ is **reversible**: for every integer $m \geqslant 1$ and every finite path $(x_0, x_1, \ldots, x_m) \in V^{m+1}$,
$$\mathbb{P}_\pi(X_0 = x_0, X_1 = x_1, \ldots, X_m = x_m) = \mathbb{P}_\pi(X_0 = x_m, X_1 = x_{m-1}, \ldots, X_m = x_0).$$
*(Indeed, repeated application of detailed balance $\pi_u P_{uv} = \pi_v P_{vu}$ gives $\pi_{x_0} P_{x_0 x_1} \cdots P_{x_{m-1} x_m} = \pi_{x_m} P_{x_m x_{m-1}} \cdots P_{x_1 x_0}$.)*

**Proof:**
Fix distinct vertices $i \neq j$. (If extended to $i = j$, $q_{ii} = P(T_i < T_i \mid X_0 = i) = 0$ and $\pi_i q_{ii} = \pi_i q_{ii}$ is trivial.)

Consider the stationary chain with $X_0 \sim \pi$. Observe that the event $\{X_0 = i, \; T_j < T_i\}$ occurs if and only if there exists a unique integer $m \geqslant 1$ (namely $m = T_j$) such that $X_0 = i$, $X_m = j$, and $X_k \notin \{i, j\}$ for all $1 \leqslant k \leqslant m - 1$. (Indeed, $T_j = m < T_i$ forces $T_j < \infty$, $X_k \neq j$ for $1 \leqslant k < m$, and $X_k \neq i$ for $1 \leqslant k < m$; conversely any such path has $T_j = m < T_i$.)

As $m$ ranges over $\{1, 2, \ldots\}$ and $(x_1, \ldots, x_{m-1})$ ranges over $(V \setminus \{i, j\})^{m-1}$, the cylinder events $\{X_0 = i, X_1 = x_1, \ldots, X_{m-1} = x_{m-1}, X_m = j\}$ are pairwise disjoint and their union is $\{X_0 = i, T_j < T_i\}$. By countable additivity and reversibility:
$$\begin{aligned}
\pi_i q_{ij} &= \mathbb{P}_\pi(X_0 = i)\,\mathbb{P}(T_j < T_i \mid X_0 = i) \\
&= \mathbb{P}_\pi(X_0 = i, \; T_j < T_i) \\
&= \sum_{m=1}^\infty \sum_{x_1, \ldots, x_{m-1} \notin \{i, j\}} \mathbb{P}_\pi(X_0 = i, X_1 = x_1, \ldots, X_{m-1} = x_{m-1}, X_m = j) \\
&= \sum_{m=1}^\infty \sum_{x_1, \ldots, x_{m-1} \notin \{i, j\}} \mathbb{P}_\pi(X_0 = j, X_1 = x_{m-1}, \ldots, X_{m-1} = x_1, X_m = i) \\
&= \sum_{m=1}^\infty \sum_{y_1, \ldots, y_{m-1} \notin \{i, j\}} \mathbb{P}_\pi(X_0 = j, X_1 = y_1, \ldots, X_{m-1} = y_{m-1}, X_m = i) \\
&= \mathbb{P}_\pi(X_0 = j, \; T_i < T_j) \\
&= \pi_j q_{ji},
\end{aligned}$$
where in the fifth line we relabelled $(y_1, \ldots, y_{m-1}) = (x_{m-1}, \ldots, x_1)$, which is a bijection of $(V \setminus \{i, j\})^{m-1}$ onto itself.

### Part (iii): Finding $m_{33}$

**Theorem used:** For an irreducible positive-recurrent Markov chain with invariant distribution $\pi$, the expected return time to state $i$ is $m_{ii} = \mathbb{E}(T_i \mid X_0 = i) = 1 / \pi_i$.

Inspecting the printed graph $G$:
- It is a tree on $|V| = 10$ vertices with $|E| = 9$ edges:
  $$\{1,3\}, \{2,3\}, \{3,5\}, \{4,5\}, \{5,6\}, \{5,8\}, \{7,8\}, \{8,9\}, \{8,10\}.$$
- Vertex $3$ has neighbours $1, 2, 5$, so $d_3 = 3$.

By part (i), $\pi_3 = \frac{d_3}{2|E|} = \frac{3}{2 \times 9} = \frac{3}{18} = \frac{1}{6}$. Therefore,
$$m_{33} = \frac{1}{\pi_3} = 6.$$

### Part (iv): Proof that $m_{ij} = 1 + 2e_{ij}(i)$ for Any Edge $(i, j)$

Let $(i, j)$ be any edge of the graph $G$ (which is a tree, so removing $(i, j)$ leaves two disjoint connected components: $C_i$ containing $i$, with $e_{ij}(i)$ edges, and $C_j$ containing $j$).

Construct the finite connected subgraph $G'$ of $G$ with
$$V(G') = V(C_i) \cup \{j\}, \qquad E(G') = E(C_i) \cup \{\{i, j\}\}.$$
Note the following properties of $G'$:
1. $G'$ is connected (since $C_i$ is connected and $j$ is joined to $i \in V(C_i)$) and has
   $$|E(G')| = e_{ij}(i) + 1$$
   edges (since $\{i, j\} \notin E(C_i)$).
2. Since $C_i$ and $C_j$ are disjoint and removing the single edge $\{i, j\}$ separates them, **no** edge of $G$ other than $\{i, j\}$ joins a vertex of $C_i$ to a vertex of $C_j$. Consequently:
   - In $G'$, vertex $j$ is incident only to $\{i, j\}$, so $d'_j = 1$.
   - Every vertex $v \in V(C_i)$ has the exact same set of neighbours in $G'$ as in $G$: $N_{G'}(v) = N_G(v)$ and $d'_v = d_v$. Hence the transition matrix $P'$ of the symmetric random walk $(Y_n)_{n \geqslant 0}$ on $G'$ satisfies
     $$P'_{vw} = P_{vw} \qquad \forall v \in V(C_i), \; \forall w \in V(G'),$$
     and $P_{vw} = 0$ for all $v \in V(C_i)$, $w \notin V(G')$.

Let $T'_j = \inf\{n \geqslant 1 : Y_n = j\}$.
- Applying part (i) and the return-time theorem ($m'_{jj} = 1/\pi'_j$) to the finite connected graph $G'$:
  $$\mathbb{E}(T'_j \mid Y_0 = j) = \frac{2|E(G')|}{d'_j} = \frac{2(e_{ij}(i) + 1)}{1} = 2e_{ij}(i) + 2.$$
- On the other hand, starting from $Y_0 = j$, since $i$ is the unique neighbour of $j$ in $G'$, we have $Y_1 = i$ almost surely. By the Markov property at time $1$,
  $$\mathbb{E}(T'_j \mid Y_0 = j) = 1 + \mathbb{E}(T'_j \mid Y_0 = i).$$
- Finally, compare the distribution of $T'_j$ (under $Y_0 = i$) with that of $T_j$ (under $X_0 = i$): starting from $i \in V(C_i)$ in $G$, the walk cannot leave $V(C_i)$ without first hitting $j$ (as $\{i, j\}$ is the sole edge between $C_i$ and $C_j$). Therefore, for every $n \geqslant 1$,
  $$\begin{aligned}
  \mathbb{P}(T_j = n \mid X_0 = i)
  &= \sum_{x_1, \ldots, x_{n-1} \in V(C_i)} P_{i, x_1} P_{x_1, x_2} \cdots P_{x_{n-1}, j} \\
  &= \sum_{x_1, \ldots, x_{n-1} \in V(C_i)} P'_{i, x_1} P'_{x_1, x_2} \cdots P'_{x_{n-1}, j} \\
  &= \mathbb{P}(T'_j = n \mid Y_0 = i).
  \end{aligned}$$
  Thus $\mathbb{E}(T'_j \mid Y_0 = i) = \mathbb{E}(T_j \mid X_0 = i) = m_{ij}$.

Combining these identities gives
$$m_{ij} = \mathbb{E}(T'_j \mid Y_0 = j) - 1 = 2e_{ij}(i) + 2 - 1 = 1 + 2e_{ij}(i).$$

### Part (v): Showing $m_{ij} + m_{ji} \in \{18, 36, 54, 72\}$ for All $i \neq j$

**Step 1: Commute time across any single edge.**
For any adjacent pair $\{u, v\} \in E$, removing the edge $\{u, v\}$ splits $G$ into two disjoint components $C_u$ and $C_v$ whose edge sets, together with $\{u, v\}$, partition $E$. Thus
$$e_{uv}(u) + e_{uv}(v) = |E| - 1 = 9 - 1 = 8.$$
Applying part (iv) in both directions:
$$m_{uv} + m_{vu} = \bigl(1 + 2e_{uv}(u)\bigr) + \bigl(1 + 2e_{uv}(v)\bigr) = 2 + 2(|E| - 1) = 2|E| = 18.$$

**Step 2: Additivity of hitting times along paths in a tree (Strong Markov Property).**
**Theorem used (Strong Markov Property):** If $T$ is a stopping time for a Markov chain $(X_n)$ and $\mathbb{P}(T < \infty) = 1$, then conditional on $X_T = b$, the shifted process $(X_{T+m})_{m \geqslant 0}$ is a Markov chain with transition matrix $P$ starting from $b$, independent of $(X_0, \ldots, X_T)$.

Because $G$ is a tree (connected, $|V| = 10$, $|E| = 9$), for any two distinct vertices $i \neq j$ there is a unique simple path in $G$ from $i$ to $j$:
$$i = v_0 - v_1 - \cdots - v_d = j,$$
where $d = d(i, j) \geqslant 1$ is the graph distance between $i$ and $j$.

We show by induction on $d \geqslant 1$ that
$$m_{ij} = \sum_{r=1}^d m_{v_{r-1} v_r}.$$
For $d = 1$ this is immediate. For $d \geqslant 2$, removing edge $(v_0, v_1)$ disconnects $v_0$ from $v_d$, so every path from $v_0$ to $v_d$ must visit $v_1$ before reaching $v_d$. Because $G$ is finite and connected, $T_{v_1} < \infty$ and $T_{v_d} < \infty$ almost surely under $\mathbb{P}_{v_0}$, and $1 \leqslant T_{v_1} < T_{v_d}$ almost surely. Hence
$$T_{v_d} = T_{v_1} + \tilde{T}_{v_d}, \qquad \tilde{T}_{v_d} := \inf\{m \geqslant 1 : X_{T_{v_1} + m} = v_d\}.$$
By the strong Markov property at the stopping time $T_{v_1}$ (with $X_{T_{v_1}} = v_1$), $\mathbb{E}_{v_0}[\tilde{T}_{v_d}] = \mathbb{E}_{v_1}[T_{v_d}] = m_{v_1 v_d}$. Taking expectations (all hitting times have finite expectation on a finite irreducible chain):
$$m_{v_0 v_d} = m_{v_0 v_1} + m_{v_1 v_d}.$$
By the induction hypothesis applied to the path $v_1 - \cdots - v_d$ of length $d - 1$, $m_{v_1 v_d} = \sum_{r=2}^d m_{v_{r-1} v_r}$, completing the induction.

Applying this both to the path $i = v_0 - v_1 - \cdots - v_d = j$ and to the reverse path $j = v_d - v_{d-1} - \cdots - v_0 = i$, and adding:
$$m_{ij} + m_{ji} = \sum_{r=1}^d \bigl(m_{v_{r-1} v_r} + m_{v_r v_{r-1}}\bigr) = \sum_{r=1}^d 18 = 18\,d(i, j).$$

**Step 3: Range of distances $d(i, j)$ in the printed graph.**
Measured from vertex $5$:
- $d(5, 5) = 0$;
- vertices at distance $1$ from $5$: $\{3, 4, 6, 8\}$;
- vertices at distance $2$ from $5$: $\{1, 2, 7, 9, 10\}$.

Thus $d(v, 5) \leqslant 2$ for every vertex $v \in V$. By the triangle inequality, for any $i \neq j$,
$$1 \leqslant d(i, j) \leqslant d(i, 5) + d(5, j) \leqslant 2 + 2 = 4,$$
so $d(i, j) \in \{1, 2, 3, 4\}$. (All four distances occur, e.g. $d(1, 3) = 1$, $d(1, 2) = 2$, $d(1, 8) = 3$, $d(1, 10) = 4$.)

Therefore, for all $i \neq j$,
$$m_{ij} + m_{ji} = 18\,d(i, j) \in \{18, 36, 54, 72\}.$$
