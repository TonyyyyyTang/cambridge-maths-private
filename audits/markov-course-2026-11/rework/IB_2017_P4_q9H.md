## Full Solution

Let $(X_n)_{n \ge 0}$ be the simple symmetric random walk on $\mathbb{Z}^3$, started at the origin $\mathbf{0} = (0, 0, 0)$, with transition probabilities
\[
p_{\mathbf{x}, \mathbf{y}} = \begin{cases}
\tfrac{1}{6} & \text{if } \mathbf{y} - \mathbf{x} \in \{\pm e_1, \pm e_2, \pm e_3\}, \\
0 & \text{otherwise},
\end{cases}
\]
where $e_1 = (1,0,0)$, $e_2 = (0,1,0)$, $e_3 = (0,0,1)$ are the standard basis vectors.

Any two states $\mathbf{x}, \mathbf{y} \in \mathbb{Z}^3$ can be connected by a finite sequence of unit coordinate steps, so the Markov chain is **irreducible**. Since transience is a class property, the walk is transient if and only if the origin $\mathbf{0}$ is transient. By the recurrence/transience criterion, $\mathbf{0}$ is transient if and only if
\[
\sum_{n=0}^\infty p_{\mathbf{0}, \mathbf{0}}^{(n)} < \infty,
\]
where $p_{\mathbf{0}, \mathbf{0}}^{(n)} = \mathbb{P}_{\mathbf{0}}(X_n = \mathbf{0})$. We prove that this series converges (using a completely elementary argument that requires neither Stirling's formula nor any unproved combinatorial inequality).

### Step 1: Exact expression for $p_{\mathbf{0}, \mathbf{0}}^{(n)}$

Each step changes the coordinate sum $X_n^{(1)} + X_n^{(2)} + X_n^{(3)}$ by $\pm 1$, so $X_n^{(1)} + X_n^{(2)} + X_n^{(3)} \equiv n \pmod{2}$. Hence for every odd $n$,
\[
p_{\mathbf{0}, \mathbf{0}}^{(n)} = 0.
\]

For even $n = 2m$ ($m \ge 0$), the walk returns to $\mathbf{0}$ in $2m$ steps if and only if, for each coordinate $r \in \{1, 2, 3\}$, the number of $+e_r$ steps equals the number of $-e_r$ steps. Letting $i, j, k \ge 0$ be the numbers of $+e_1$, $+e_2$, $+e_3$ steps respectively, there are also $i, j, k$ steps in directions $-e_1, -e_2, -e_3$, so $2(i + j + k) = 2m$, i.e., $i + j + k = m$. Each specific trajectory of length $2m$ has probability $6^{-2m}$, and the number of trajectories with step counts $(i, i, j, j, k, k)$ is $\frac{(2m)!}{(i!\,j!\,k!)^2}$. Therefore,
\[
p_{\mathbf{0}, \mathbf{0}}^{(2m)}
= \sum_{\substack{i,j,k \ge 0 \\ i+j+k=m}} \frac{(2m)!}{(i!\,j!\,k!)^2} \frac{1}{6^{2m}}
= \binom{2m}{m} \frac{1}{4^m} \sum_{\substack{i,j,k \ge 0 \\ i+j+k=m}} \left(\frac{m!}{i!\,j!\,k!} \frac{1}{3^m}\right)^2,
\]
since $\frac{(2m)!}{(i!j!k!)^2} 6^{-2m} = \frac{(2m)!}{(m!)^2} 4^{-m} \cdot \left(\frac{m!}{i!j!k!} 3^{-m}\right)^2$.

### Step 2: Bounding the multinomial sum

Set
\[
b_m := \binom{2m}{m} 4^{-m}, \qquad
M_m := \max_{\substack{i,j,k \ge 0 \\ i+j+k=m}} \frac{m!}{i!\,j!\,k!}, \qquad
d_m := M_m 3^{-m}.
\]
By the multinomial theorem, the non-negative quantities $q_m(i,j,k) := \frac{m!}{i!\,j!\,k!} 3^{-m}$ satisfy
\[
\sum_{\substack{i,j,k \ge 0 \\ i+j+k=m}} q_m(i,j,k) = \frac{(1 + 1 + 1)^m}{3^m} = 1.
\]
Hence
\[
\sum_{\substack{i,j,k \ge 0 \\ i+j+k=m}} q_m(i,j,k)^2
\le \left(\max_{\substack{i,j,k \ge 0 \\ i+j+k=m}} q_m(i,j,k)\right) \sum_{\substack{i,j,k \ge 0 \\ i+j+k=m}} q_m(i,j,k)
= d_m,
\]
and therefore
\[
p_{\mathbf{0}, \mathbf{0}}^{(2m)} \le b_m d_m \qquad \text{for all } m \ge 0.
\]

**Maximizer $M_m$:** If two entries of $(i, j, k)$ differ by at least $2$, say $i \ge j + 2$, replacing $(i, j)$ by $(i - 1, j + 1)$ preserves $i + j + k = m$ while strictly decreasing the denominator, since
\[
\frac{(i-1)!\,(j+1)!}{i!\,j!} = \frac{j + 1}{i} < 1.
\]
Thus the maximum $M_m$ is attained when $|a - b| \le 1$ for all $a, b \in \{i, j, k\}$: for $r \ge 0$,
\[
M_{3r} = \frac{(3r)!}{(r!)^3}, \qquad
M_{3r+1} = \frac{(3r+1)!}{(r+1)!\,r!\,r!}, \qquad
M_{3r+2} = \frac{(3r+2)!}{(r+1)!\,(r+1)!\,r!}.
\]

### Step 3: Grouping by $m = 3r + s$ ($s \in \{0, 1, 2\}$)

For every $m \ge 0$,
\[
\frac{b_{m+1}}{b_m} = \frac{(2m+2)(2m+1)}{4(m+1)^2} = \frac{2m + 1}{2m + 2} < 1,
\]
so $(b_m)_{m \ge 0}$ is decreasing; hence $b_{3r+s} \le b_{3r}$ for all $r \ge 0$ and $s \in \{0, 1, 2\}$.

Similarly, for every $r \ge 0$,
\[
\frac{d_{3r+1}}{d_{3r}} = \frac{3r + 1}{3(r + 1)} < 1, \qquad
\frac{d_{3r+2}}{d_{3r}} = \frac{(3r + 2)(3r + 1)}{9(r + 1)^2} = \frac{9r^2 + 9r + 2}{9r^2 + 18r + 9} < 1,
\]
so $d_{3r+s} \le d_{3r}$ for all $r \ge 0$ and $s \in \{0, 1, 2\}$.

Setting $c_r := d_{3r} = \frac{(3r)!}{(r!)^3} 3^{-3r}$, we obtain
\[
p_{\mathbf{0}, \mathbf{0}}^{(2(3r+s))} \le b_{3r+s} d_{3r+s} \le b_{3r} c_r \qquad \text{for all } r \ge 0,\; s \in \{0, 1, 2\}.
\]

### Step 4: Elementary induction bounds and convergence

1. **Claim:** $b_n \le \frac{1}{\sqrt{2n + 1}}$ for all $n \ge 0$.
   *Proof:* Equivalently, $b_n^2 (2n + 1) \le 1$. For $n = 0$, $b_0^2 \cdot 1 = 1$. For every $n \ge 1$,
   \[
   \frac{b_n^2 (2n + 1)}{b_{n-1}^2 (2n - 1)}
   = \left(\frac{2n - 1}{2n}\right)^2 \frac{2n + 1}{2n - 1}
   = \frac{4n^2 - 1}{4n^2} < 1.
   \]
   By induction, $b_n^2 (2n + 1) \le 1$ for all $n \ge 0$. In particular, for $n = 3r$,
   \[
   b_{3r} \le \frac{1}{\sqrt{6r + 1}} \le \frac{1}{\sqrt{r + 1}} \qquad (r \ge 0).
   \]

2. **Claim:** $c_r \le \frac{1}{r + 1}$ for all $r \ge 0$.
   *Proof:* Equivalently, $c_r (r + 1) \le 1$. For $r = 0$, $c_0 \cdot 1 = 1$. For every $r \ge 1$,
   \[
   \frac{c_r}{c_{r-1}} = \frac{3r(3r - 1)(3r - 2)}{27 r^3} = \frac{(3r - 1)(3r - 2)}{9r^2},
   \]
   and hence
   \[
   \frac{c_r (r + 1)}{c_{r-1} \cdot r}
   = \frac{(3r - 1)(3r - 2)(r + 1)}{9r^3}
   = \frac{(9r^2 - 9r + 2)(r + 1)}{9r^3}
   = \frac{9r^3 - 7r + 2}{9r^3} < 1,
   \]
   since $7r - 2 \ge 5 > 0$ for all $r \ge 1$. By induction, $c_r (r + 1) \le 1$ for all $r \ge 0$.

Combining the two claims, for every $r \ge 0$ and $s \in \{0, 1, 2\}$,
\[
p_{\mathbf{0}, \mathbf{0}}^{(2(3r+s))} \le b_{3r} c_r \le \frac{1}{\sqrt{6r + 1}}\cdot \frac{1}{r + 1} \le \frac{1}{(r + 1)^{3/2}}.
\]
Therefore,
\[
\sum_{n=0}^\infty p_{\mathbf{0}, \mathbf{0}}^{(n)}
= \sum_{m=0}^\infty p_{\mathbf{0}, \mathbf{0}}^{(2m)}
= \sum_{r=0}^\infty \sum_{s=0}^2 p_{\mathbf{0}, \mathbf{0}}^{(2(3r+s))}
\le 3 \sum_{r=0}^\infty \frac{1}{(r + 1)^{3/2}}
= 3 \sum_{k=1}^\infty \frac{1}{k^{3/2}} < \infty,
\]
since $\sum_{k=1}^\infty k^{-3/2}$ converges (a $p$-series with $p = \frac{3}{2} > 1$; explicitly $\le 3(1 + \int_1^\infty x^{-3/2}\,dx) = 9$).

Hence state $\mathbf{0}$ is transient. By irreducibility, every state of $\mathbb{Z}^3$ is transient, so the simple symmetric random walk on $\mathbb{Z}^3$ is transient. $\square$
