## Question (verbatim question.tex)
```latex
Define what is meant by a \emph{communicating class} and a \emph{closed class} in a Markov chain.

A Markov chain $(X_n:n\geq0)$ with state space $\{1,2,3,4\}$ has transition matrix
\[
P=\begin{pmatrix}\tfrac12&0&\tfrac12&0\\0&\tfrac12&0&\tfrac12\\\tfrac12&0&\tfrac12&0\\\tfrac12&0&0&\tfrac12\end{pmatrix}.
\]
Write down the communicating classes for this Markov chain and state whether or not each class is closed.

If $X_0=2$, let $N$ be the smallest $n$ such that $X_n\ne2$. Find $\mathbb{P}(N=n)$ for $n=1,2,\ldots$ and $\mathbb{E}(N)$. Describe the evolution of the chain if $X_0=2$.
```
