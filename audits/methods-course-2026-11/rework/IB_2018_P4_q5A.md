## Full Solution

We seek a solution $u(x,y)$ to Laplace's equation
\[
\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0, \qquad 0 < x < 1,\quad 0 < y < 1,
\]
subject to the Dirichlet boundary conditions
\[
\begin{aligned}
u(0,y) &= 0 && (0 \le y \le 1),\\
u(1,y) &= 0 && (0 \le y \le 1),\\
u(x,0) &= 0 && (0 \le x \le 1),\\
u(x,1) &= 2\sin(3\pi x) && (0 \le x \le 1).
\end{aligned}
\]
Note that the boundary data are continuous at all four corners of $[0,1]^2$ (since $2\sin(0) = 2\sin(3\pi) = 0$).

### Step 1: Separation of variables

Look for non-trivial separable solutions of the form $u(x,y) = X(x)Y(y)$ (with $X \not\equiv 0$ and $Y \not\equiv 0$). Substituting into Laplace's equation gives
\[
X''(x)Y(y) + X(x)Y''(y) = 0.
\]
Where $X(x)Y(y) \neq 0$, dividing by $X(x)Y(y)$ yields
\[
\frac{X''(x)}{X(x)} = -\frac{Y''(y)}{Y(y)} = -\lambda,
\]
where $\lambda$ is a separation constant (independent of both $x$ and $y$). Thus
\[
X''(x) + \lambda X(x) = 0, \qquad Y''(y) - \lambda Y(y) = 0.
\]
The three homogeneous boundary conditions require, for a non-trivial separated solution ($X \not\equiv 0$, $Y \not\equiv 0$):
\[
X(0) = 0, \qquad X(1) = 0, \qquad Y(0) = 0.
\]

### Step 2: Eigenvalue problem for $X(x)$

We solve $X'' + \lambda X = 0$ on $[0,1]$ with $X(0) = X(1) = 0$.

First note that $\lambda$ must be real and strictly positive: multiplying $X'' + \lambda X = 0$ by $\overline{X}(x)$ and integrating over $[0,1]$ gives, after integration by parts using $X(0) = X(1) = 0$,
\[
\lambda \int_0^1 |X(x)|^2\,dx = -\int_0^1 \overline{X}(x)X''(x)\,dx = \Big[-\overline{X}X'\Big]_0^1 + \int_0^1 |X'(x)|^2\,dx = \int_0^1 |X'(x)|^2\,dx \ge 0.
\]
Checking the three real cases explicitly confirms this:
- **$\lambda < 0$:** Write $\lambda = -\mu^2$ with $\mu > 0$. Then $X(x) = A\cosh(\mu x) + B\sinh(\mu x)$. From $X(0) = 0$ we get $A = 0$, and from $X(1) = 0$ we get $B\sinh(\mu) = 0$. Since $\sinh(\mu) > 0$ for $\mu > 0$, $B = 0$, giving only the trivial solution $X \equiv 0$.
- **$\lambda = 0$:** Then $X'' = 0$, so $X(x) = Ax + B$. From $X(0) = 0$ we get $B = 0$, and from $X(1) = 0$ we get $A = 0$, again giving only $X \equiv 0$.
- **$\lambda > 0$:** Write $\lambda = k^2$ with $k > 0$. Then $X(x) = A\cos(kx) + B\sin(kx)$. From $X(0) = 0$ we obtain $A = 0$, and from $X(1) = 0$ we require $B\sin(k) = 0$. For a non-trivial solution ($B \neq 0$), we must have $\sin(k) = 0$, so
\[
k = n\pi, \qquad \lambda_n = n^2\pi^2, \qquad X_n(x) = \sin(n\pi x), \qquad n = 1, 2, 3, \ldots.
\]

### Step 3: Solution for $Y(y)$ and superposition

For each $n \in \{1, 2, 3, \ldots\}$, the equation for $Y_n(y)$ is
\[
Y_n''(y) - n^2\pi^2 Y_n(y) = 0,
\]
whose general solution is
\[
Y_n(y) = C_n\cosh(n\pi y) + D_n\sinh(n\pi y).
\]
Imposing the homogeneous boundary condition $Y_n(0) = 0$ yields $C_n = 0$, so $Y_n(y) = D_n\sinh(n\pi y)$.

By linearity and superposition, the general series solution satisfying Laplace's equation and the three homogeneous boundary conditions on $x=0$, $x=1$, and $y=0$ is
\[
u(x,y) = \sum_{n=1}^{\infty} D_n \sin(n\pi x)\sinh(n\pi y).
\]

### Step 4: Imposing the boundary condition on $y = 1$

Setting $y = 1$ gives
\[
u(x,1) = \sum_{n=1}^{\infty} D_n \sinh(n\pi)\sin(n\pi x) = 2\sin(3\pi x), \qquad 0 \le x \le 1.
\]
Using the orthogonality relation of the Fourier sine basis on $[0,1]$,
\[
\int_0^1 \sin(m\pi x)\sin(n\pi x)\,dx = \frac{1}{2}\delta_{mn} \qquad (m, n \ge 1),
\]
we multiply both sides by $\sin(m\pi x)$ and integrate from $0$ to $1$:
\[
\frac{1}{2} D_m \sinh(m\pi) = 2\int_0^1 \sin(3\pi x)\sin(m\pi x)\,dx = \delta_{m3}.
\]
Since $\sinh(m\pi) > 0$ for all $m \ge 1$, this yields
\[
D_m = 0 \quad (m \neq 3), \qquad D_3 = \frac{2}{\sinh(3\pi)}.
\]
Therefore,
\[
u(x,y) = \frac{2\sin(3\pi x)\sinh(3\pi y)}{\sinh(3\pi)}.
\]

### Step 5: Direct verification and uniqueness

1. **PDE:** $u_{xx} = -(3\pi)^2 u$ and $u_{yy} = +(3\pi)^2 u$, so $u_{xx} + u_{yy} = 0$ on $(0,1)^2$.
2. **Boundary conditions:** $u(0,y) = 0$, $u(1,y) = 0$ (since $\sin(3\pi) = 0$), $u(x,0) = 0$ (since $\sinh(0) = 0$), and $u(x,1) = 2\sin(3\pi x)$.
3. **Uniqueness:** If $u_1, u_2 \in C^2(\Omega) \cap C^1(\overline{\Omega})$ both solve the Dirichlet problem on $\Omega = (0,1)^2$, then $w = u_1 - u_2$ satisfies $\nabla^2 w = 0$ in $\Omega$ and $w = 0$ on $\partial\Omega$. By Green's first identity,
\[
\iint_{\Omega} |\nabla w|^2\,dx\,dy = \int_{\partial\Omega} w\frac{\partial w}{\partial n}\,ds - \iint_{\Omega} w\nabla^2 w\,dx\,dy = 0,
\]
so $\nabla w \equiv \mathbf{0}$ in $\Omega$; hence $w$ is constant, and since $w = 0$ on $\partial\Omega$, $w \equiv 0$. (Uniqueness in $C^2(\Omega)\cap C(\overline{\Omega})$ likewise follows from the maximum principle.)

## Final Answers

\[
u(x,y) = \frac{2\sin(3\pi x)\sinh(3\pi y)}{\sinh(3\pi)}, \qquad 0 \le x \le 1,\quad 0 \le y \le 1.
\]
