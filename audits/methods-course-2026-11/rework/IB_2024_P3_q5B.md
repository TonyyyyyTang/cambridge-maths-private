## Full Solution

We solve Laplace's equation
\[
\nabla^2 u \equiv \frac{\partial^2 u}{\partial r^2} + \frac{1}{r}\frac{\partial u}{\partial r} + \frac{1}{r^2}\frac{\partial^2 u}{\partial \theta^2} = 0
\]
in the annulus $\mathcal{A} = \{(r,\theta) : a < r < b,\ 0 \le \theta < 2\pi\}$, where $0 < a < b$.

### Step 1: General solution by separation of variables

Look for non-trivial separable solutions of the form $u(r,\theta) = R(r)\Theta(\theta)$. Substituting into Laplace's equation and multiplying by $\dfrac{r^2}{R(r)\Theta(\theta)}$ (where $R\Theta \ne 0$) gives
\[
\frac{r^2 R''(r) + r R'(r)}{R(r)} = -\frac{\Theta''(\theta)}{\Theta(\theta)} = \lambda,
\]
where $\lambda$ is a separation constant independent of $r$ and $\theta$. This separates the PDE into two ODEs:
\[
\Theta''(\theta) + \lambda\Theta(\theta) = 0, \qquad r^2 R''(r) + r R'(r) - \lambda R(r) = 0.
\]
Since $u$ is defined on the full annulus $0 \le \theta < 2\pi$, single-valuedness and smoothness require $\Theta$ to be $2\pi$-periodic:
\[
\Theta(\theta + 2\pi) = \Theta(\theta), \qquad \Theta'(\theta + 2\pi) = \Theta'(\theta) \qquad \forall \theta \in \mathbb{R}.
\]
Because $-\frac{d^2}{d\theta^2}$ with periodic boundary conditions on $[0, 2\pi]$ is self-adjoint (boundary term $[\Theta^*\Theta' - (\Theta^*)'\Theta]_0^{2\pi} = 0$), $\lambda$ must be real (and $\lambda = \int_0^{2\pi}|\Theta'|^2\,d\theta / \int_0^{2\pi}|\Theta|^2\,d\theta \ge 0$). Checking all real cases for $\lambda$:

1. **$\lambda < 0$:** Write $\lambda = -\mu^2$ with $\mu > 0$. Then $\Theta(\theta) = P e^{\mu\theta} + Q e^{-\mu\theta}$. Imposing $\Theta(0) = \Theta(2\pi)$ and $\Theta'(0) = \Theta'(2\pi)$ gives $P(e^{2\pi\mu} - 1) = 0$ and $Q(e^{-2\pi\mu} - 1) = 0$, so $P = Q = 0$ (only the trivial solution).

2. **$\lambda = 0$:** $\Theta''(\theta) = 0 \implies \Theta(\theta) = P + Q\theta$. Periodicity requires $Q = 0$, so $\Theta_0(\theta) = \text{const}$.
   The radial ODE becomes
   \[
   r^2 R''(r) + r R'(r) = r\frac{d}{dr}\!\left(r\frac{dR}{dr}\right) = 0 \implies r R'(r) = B_0 \implies R_0(r) = A_0 + B_0 \ln r.
   \]

3. **$\lambda > 0$:** Write $\lambda = \mu^2$ with $\mu > 0$. Then $\Theta(\theta) = P\cos(\mu\theta) + Q\sin(\mu\theta)$. Periodicity of period $2\pi$ holds if and only if $\mu = n \in \{1, 2, 3, \dots\}$, i.e. $\lambda = n^2$ with independent angular modes $\cos(n\theta)$ and $\sin(n\theta)$.
   The radial equation $r^2 R'' + r R' - n^2 R = 0$ is an Euler–Cauchy equation. Substituting $R(r) = r^\alpha$ gives
   \[
   \alpha(\alpha - 1) + \alpha - n^2 = \alpha^2 - n^2 = 0 \implies \alpha = \pm n.
   \]
   Since $n \ge 1$, the roots $\pm n$ are distinct, giving the general radial solution $R_n(r) = \alpha_n r^n + \beta_n r^{-n}$.

Because the annulus satisfies $0 < a < r < b < \infty$, neither $r = 0$ nor $r = \infty$ lies in $\mathcal{A}$, so all radial functions ($1$, $\ln r$, $r^n$, $r^{-n}$) are smooth and bounded in $\mathcal{A}$ and must be retained. By linearity of Laplace's equation, the general expression for $u(r,\theta)$ in $\mathcal{A}$ is
\[
u(r,\theta) = A_0 + B_0 \ln r + \sum_{n=1}^\infty \left(A_n r^n + B_n r^{-n}\right)\cos(n\theta) + \sum_{n=1}^\infty \left(C_n r^n + D_n r^{-n}\right)\sin(n\theta),
\]
where $A_0, B_0$ and $A_n, B_n, C_n, D_n$ ($n \ge 1$) are arbitrary constants.

### Step 2: Explicit solution for $u(a,\theta) = 0$ and $u(b,\theta) = \cos(2\theta)$

Evaluating the general series at $r = a$ and $r = b$ gives:
\[
u(a,\theta) = (A_0 + B_0 \ln a) + \sum_{n=1}^\infty \left(A_n a^n + B_n a^{-n}\right)\cos(n\theta) + \sum_{n=1}^\infty \left(C_n a^n + D_n a^{-n}\right)\sin(n\theta) = 0,
\]
\[
u(b,\theta) = (A_0 + B_0 \ln b) + \sum_{n=1}^\infty \left(A_n b^n + B_n b^{-n}\right)\cos(n\theta) + \sum_{n=1}^\infty \left(C_n b^n + D_n b^{-n}\right)\sin(n\theta) = \cos(2\theta).
\]
By orthogonality of $\{1, \cos(n\theta), \sin(n\theta)\}$ on $[0, 2\pi]$, we equate Fourier coefficients mode by mode:

- **$n = 0$ mode:**
  \[
  A_0 + B_0\ln a = 0, \qquad A_0 + B_0\ln b = 0.
  \]
  Subtracting gives $B_0\ln(b/a) = 0$. Since $0 < a < b$, $\ln(b/a) > 0$, so $B_0 = 0$ and hence $A_0 = 0$.

- **$\sin(n\theta)$ modes ($n \ge 1$):**
  \[
  C_n a^n + D_n a^{-n} = 0, \qquad C_n b^n + D_n b^{-n} = 0.
  \]
  The determinant is $a^n b^{-n} - a^{-n} b^n = (a/b)^n - (b/a)^n < 0$ (non-zero since $0 < a < b$), so $C_n = D_n = 0$ for all $n \ge 1$.

- **$\cos(n\theta)$ modes for $n \ne 2$ ($n \ge 1$):**
  \[
  A_n a^n + B_n a^{-n} = 0, \qquad A_n b^n + B_n b^{-n} = 0.
  \]
  Again the determinant $(a/b)^n - (b/a)^n \ne 0$, so $A_n = B_n = 0$ for all $n \ge 1$ with $n \ne 2$.

- **$\cos(2\theta)$ mode ($n = 2$):**
  \[
  A_2 a^2 + B_2 a^{-2} = 0, \qquad A_2 b^2 + B_2 b^{-2} = 1.
  \]
  From the first equation, $B_2 = -A_2 a^4$. Substituting into the second equation gives
  \[
  A_2\left(b^2 - \frac{a^4}{b^2}\right) = 1 \implies A_2\left(\frac{b^4 - a^4}{b^2}\right) = 1 \implies A_2 = \frac{b^2}{b^4 - a^4},
  \]
  which is well-defined since $0 < a < b \implies b^4 - a^4 > 0$. Hence
  \[
  B_2 = -A_2 a^4 = -\frac{a^4 b^2}{b^4 - a^4}.
  \]

Therefore the explicit (and unique, by Dirichlet uniqueness for Laplace's equation on bounded $\mathcal{A}$) solution is
\[
u(r,\theta) = \frac{b^2}{b^4 - a^4}\left(r^2 - \frac{a^4}{r^2}\right)\cos(2\theta) = \frac{b^2(r^4 - a^4)}{r^2(b^4 - a^4)}\cos(2\theta).
\]

**Direct verification:**
- At $r = a$: $r^4 - a^4 = 0 \implies u(a,\theta) = 0$.
- At $r = b$: $\dfrac{b^2(b^4 - a^4)}{b^2(b^4 - a^4)}\cos(2\theta) = \cos(2\theta)$.
- PDE: for $R(r) = r^2 - a^4 r^{-2}$, $R'(r) = 2r + 2a^4 r^{-3}$ and $R''(r) = 2 - 6a^4 r^{-4}$, so $R'' + r^{-1}R' - 4r^{-2}R = (2 + 2 - 4) + (-6 + 2 + 4)a^4 r^{-4} = 0$, hence $\nabla^2 u = 0$.
