## Full Solution

We work in three-dimensional Euclidean space $\mathbb{R}^3$ with orthonormal Cartesian coordinates $x_i$ ($i=1,2,3$) and standard Einstein summation convention over repeated indices.

### 1. $T_{ij}$ is a symmetric second-rank tensor

Consider an arbitrary orthogonal change of Cartesian coordinate axes given by $x'_i = R_{ip} x_p$, where $R$ is an orthogonal matrix satisfying
\[
R_{ip} R_{jp} = \delta_{ij} \qquad \text{and} \qquad R_{pi} R_{pj} = \delta_{ij}.
\]
Because $\mathbf{B}$ is a Cartesian vector (first-rank tensor), its components transform as $B'_i = R_{ip} B_p$, while the arbitrary scalars $\alpha$ and $\beta$ are invariant ($\alpha' = \alpha$, $\beta' = \beta$).

In the primed coordinate system,
\[
T'_{ij} = \alpha B'_i B'_j + \beta B'_l B'_l \delta_{ij}.
\]
First, the contraction $B'_l B'_l$ is a scalar invariant:
\[
B'_l B'_l = (R_{lk} B_k)(R_{lm} B_m) = (R_{lk} R_{lm}) B_k B_m = \delta_{km} B_k B_m = B_k B_k.
\]
Second, the Kronecker delta is an isotropic second-rank tensor:
\[
R_{ip} R_{jq} \delta_{pq} = R_{ip} R_{jp} = \delta_{ij}.
\]
Substituting these two identities into $T'_{ij}$ gives
\[
T'_{ij} = \alpha (R_{ip} B_p)(R_{jq} B_q) + \beta (B_k B_k)(R_{ip} R_{jq} \delta_{pq}) = R_{ip} R_{jq} \left(\alpha B_p B_q + \beta B_k B_k \delta_{pq}\right) = R_{ip} R_{jq} T_{pq}.
\]
Hence $T_{ij}$ obeys the transformation law of a second-rank Cartesian tensor. (Remark: this holds for all $R \in O(3)$; even if $\mathbf{B}$ is an axial vector/pseudovector transforming as $B'_i = (\det R) R_{ip} B_p$, the quadratic dependence on $\mathbf{B}$ gives $(\det R)^2 = 1$, so $T_{ij}$ is still a true second-rank tensor under both proper and improper orthogonal transformations.)

To verify symmetry, we interchange $i$ and $j$:
\[
T_{ji} = \alpha B_j B_i + \beta B_k B_k \delta_{ji} = \alpha B_i B_j + \beta B_k B_k \delta_{ij} = T_{ij},
\]
using commutativity of scalar multiplication $B_j B_i = B_i B_j$ and symmetry of the Kronecker delta $\delta_{ji} = \delta_{ij}$. Therefore $T_{ij}$ is a symmetric second-rank tensor.

### 2. Eigenvalues and eigenvectors of $T_{ij}$

Let $B^2 = |\mathbf{B}|^2 = B_k B_k$. Since $T_{ij}$ is real and symmetric, all its eigenvalues are real and its eigenvectors span $\mathbb{R}^3$. For any vector $\mathbf{v} \in \mathbb{R}^3$,
\[
(T\mathbf{v})_i = T_{ij} v_j = \alpha B_i (B_j v_j) + \beta B^2 \delta_{ij} v_j = \alpha (\mathbf{B} \cdot \mathbf{v}) B_i + \beta |\mathbf{B}|^2 v_i,
\]
that is,
\[
T\mathbf{v} = \alpha (\mathbf{B}\cdot\mathbf{v})\mathbf{B} + \beta |\mathbf{B}|^2 \mathbf{v}.
\]
The eigenvalue equation $T\mathbf{v} = \lambda \mathbf{v}$ ($\mathbf{v} \neq \mathbf{0}$) rearranges to
\[
\alpha (\mathbf{B}\cdot\mathbf{v})\mathbf{B} = \left(\lambda - \beta |\mathbf{B}|^2\right)\mathbf{v}.
\]

- **Generic case ($\mathbf{B} \neq \mathbf{0}$ and $\alpha \neq 0$):**
  1. If $\mathbf{B}\cdot\mathbf{v} \neq 0$, then $\mathbf{v}$ must be a non-zero scalar multiple of $\mathbf{B}$. Setting $\mathbf{v} = \mathbf{B}$ (or the unit vector $\hat{\mathbf{B}} = \mathbf{B}/|\mathbf{B}|$) gives
     \[
     T\mathbf{B} = \alpha |\mathbf{B}|^2 \mathbf{B} + \beta |\mathbf{B}|^2 \mathbf{B} = (\alpha + \beta)|\mathbf{B}|^2 \mathbf{B}.
     \]
     Thus $\lambda_1 = (\alpha + \beta)|\mathbf{B}|^2$ is a non-degenerate (multiplicity $1$) eigenvalue with one-dimensional eigenspace spanned by $\mathbf{B}$.
  2. If $\mathbf{B}\cdot\mathbf{v} = 0$ with $\mathbf{v} \neq \mathbf{0}$, then
     \[
     T\mathbf{v} = \beta |\mathbf{B}|^2 \mathbf{v}.
     \]
     The orthogonal complement $\mathbf{B}^\perp = \{\mathbf{v} \in \mathbb{R}^3 : \mathbf{B}\cdot\mathbf{v} = 0\}$ is two-dimensional, so $\lambda_2 = \lambda_3 = \beta|\mathbf{B}|^2$ is a doubly degenerate (multiplicity $2$) eigenvalue whose eigenspace consists of all non-zero vectors perpendicular to $\mathbf{B}$ (spanned by any two linearly independent, e.g. orthonormal, vectors $\mathbf{e}_2, \mathbf{e}_3$ with $\mathbf{e}_2\cdot\mathbf{B} = \mathbf{e}_3\cdot\mathbf{B} = 0$).

  Since $1 + 2 = 3 = \dim \mathbb{R}^3$, these exhaust all eigenvalues and eigenvectors. As a consistency check, $\operatorname{tr}(T) = T_{ii} = (\alpha + 3\beta)|\mathbf{B}|^2 = (\alpha + \beta)|\mathbf{B}|^2 + 2\beta|\mathbf{B}|^2 = \lambda_1 + \lambda_2 + \lambda_3$.

- **Degenerate cases:**
  - If $\alpha = 0$ and $\mathbf{B} \neq \mathbf{0}$, then $T_{ij} = \beta |\mathbf{B}|^2 \delta_{ij}$; the eigenvalues coincide to a single triply degenerate eigenvalue $\lambda = \beta |\mathbf{B}|^2$, and every non-zero vector in $\mathbb{R}^3$ is an eigenvector.
  - If $\mathbf{B} = \mathbf{0}$, then $T_{ij} = 0$ identically; $\lambda = 0$ has multiplicity $3$, and every non-zero vector in $\mathbb{R}^3$ is an eigenvector.

### 3. Determination of $\alpha$ and $\beta$ when $\nabla\cdot\mathbf{B} = 0$

First expand the right-hand side in index notation using the Levi-Civita tensor $\epsilon_{ijk}$:
\[
[(\nabla \times \mathbf{B}) \times \mathbf{B}]_i
= \epsilon_{ijk} (\nabla \times \mathbf{B})_j B_k
= \epsilon_{ijk} \left(\epsilon_{jlm} \frac{\partial B_m}{\partial x_l}\right) B_k.
\]
Using cyclic symmetry $\epsilon_{ijk} = \epsilon_{jki}$ and the standard contraction identity $\epsilon_{jki}\epsilon_{jlm} = \delta_{kl}\delta_{im} - \delta_{km}\delta_{il}$, we obtain
\[
[(\nabla \times \mathbf{B}) \times \mathbf{B}]_i
= (\delta_{kl}\delta_{im} - \delta_{km}\delta_{il}) \frac{\partial B_m}{\partial x_l} B_k
= B_l \frac{\partial B_i}{\partial x_l} - B_m \frac{\partial B_m}{\partial x_i}.
\]
Relabelling dummy indices ($l \to j$ and $m \to k$) and noting that $\frac{\partial}{\partial x_i}(B_k B_k) = 2 B_k \frac{\partial B_k}{\partial x_i}$, this becomes
\[
[(\nabla \times \mathbf{B}) \times \mathbf{B}]_i
= B_j \frac{\partial B_i}{\partial x_j} - \frac{1}{2} \frac{\partial}{\partial x_i}(B_k B_k).
\]

Now compute the divergence of $T_{ij}$ on the left-hand side:
\[
\frac{\partial}{\partial x_j} T_{ij}
= \frac{\partial}{\partial x_j} \left(\alpha B_i B_j + \beta B_k B_k \delta_{ij}\right)
= \alpha B_j \frac{\partial B_i}{\partial x_j} + \alpha B_i \frac{\partial B_j}{\partial x_j} + \beta \frac{\partial}{\partial x_i}(B_k B_k).
\]
Since $\nabla\cdot\mathbf{B} = \frac{\partial B_j}{\partial x_j} = 0$, the middle term vanishes, leaving
\[
\frac{\partial}{\partial x_j} T_{ij}
= \alpha B_j \frac{\partial B_i}{\partial x_j} + \beta \frac{\partial}{\partial x_i}(B_k B_k).
\]
Comparing the two expressions, we achieve $\frac{\partial}{\partial x_j} T_{ij} = [(\nabla \times \mathbf{B}) \times \mathbf{B}]_i$ for every smooth divergence-free vector field $\mathbf{B}$ by choosing
\[
\alpha = 1, \qquad \beta = -\frac{1}{2}.
\]
(Moreover, these constants are unique if the identity is to hold for all divergence-free $\mathbf{B}$: testing $\mathbf{B}=(0,x,0)$ gives $B_j \partial_j B_i = 0$ and $\partial_1(B^2)=2x \neq 0$, forcing $\beta = -\frac{1}{2}$; testing $\mathbf{B}=(\cos z, \sin z, 1)$ gives $|\mathbf{B}|^2 = 2$ constant and $B_j\partial_j \mathbf{B} = (-\sin z, \cos z, 0) \neq \mathbf{0}$, forcing $\alpha = 1$.)

### 4. Vanishing of $\int_V (\nabla\times\mathbf{B})\times\mathbf{B}\,dV$ when $\mathbf{B} = \mathbf{0}$ on $S = \partial V$

Assume $\mathbf{B}$ is continuously differentiable on $\bar{V}$ with $\nabla\cdot\mathbf{B} = 0$ throughout $V$, and that $S = \partial V$ is a piecewise smooth closed surface enclosing $V$ with outward unit normal $\mathbf{n}$.

With $\alpha = 1$ and $\beta = -\frac{1}{2}$, we have $T_{ij} = B_i B_j - \frac{1}{2} B_k B_k \delta_{ij}$ and $[(\nabla\times\mathbf{B})\times\mathbf{B}]_i = \frac{\partial T_{ij}}{\partial x_j}$ throughout $V$. Applying the divergence theorem component-by-component (for each fixed $i \in \{1,2,3\}$, to the vector field $j \mapsto T_{ij}$):
\[
\int_V [(\nabla\times\mathbf{B})\times\mathbf{B}]_i \, dV
= \int_V \frac{\partial T_{ij}}{\partial x_j} \, dV
= \oint_S T_{ij} n_j \, dS
= \oint_S \left(B_i B_j n_j - \frac{1}{2} B_k B_k n_i\right) dS.
\]
Since $\mathbf{B} = \mathbf{0}$ everywhere on $S$, we have $B_i = 0$ (and hence $T_{ij} = 0$) at every point of $S$. Therefore each surface integral vanishes identically:
\[
\int_V [(\nabla\times\mathbf{B})\times\mathbf{B}]_i \, dV = 0 \qquad (i = 1, 2, 3),
\]
and consequently
\[
\int_V (\nabla\times\mathbf{B})\times\mathbf{B} \, dV = \mathbf{0}.
\]

## Final Answers

- **Tensor character & symmetry:** $T'_{ij} = R_{ip} R_{jq} T_{pq}$ for all orthogonal $R$, and $T_{ji} = T_{ij}$.
- **Eigenvalues and eigenvectors of $T_{ij}$:**
  - For $\mathbf{B} \neq \mathbf{0}$ and $\alpha \neq 0$:
    - $\lambda_1 = (\alpha + \beta)|\mathbf{B}|^2$ (multiplicity $1$), eigenspace $\operatorname{span}\{\mathbf{B}\}$;
    - $\lambda_2 = \lambda_3 = \beta|\mathbf{B}|^2$ (multiplicity $2$), eigenspace $\mathbf{B}^\perp = \{\mathbf{v}\in\mathbb{R}^3 : \mathbf{B}\cdot\mathbf{v}=0\}$.
  - Degenerate cases: if $\alpha = 0$ ($\mathbf{B}\neq\mathbf{0}$), $\lambda = \beta|\mathbf{B}|^2$ with multiplicity $3$ and all non-zero vectors as eigenvectors; if $\mathbf{B}=\mathbf{0}$, $\lambda = 0$ with multiplicity $3$ and all non-zero vectors as eigenvectors.
- **Constants for Maxwell stress-tensor identity (when $\nabla\cdot\mathbf{B}=0$):** $\alpha = 1$, $\beta = -\frac{1}{2}$.
- **Volume integral:** $\int_V (\nabla\times\mathbf{B})\times\mathbf{B}\,dV = \mathbf{0}$ by the divergence theorem, since $T_{ij} = 0$ on $S$.
