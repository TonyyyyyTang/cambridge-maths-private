## Full Solution

We seek a solution $u(x, y)$ of the first-order linear inhomogeneous PDE
\[
x u_x + (x + y) u_y = 1
\]
satisfying the Cauchy data $u(1, y) = y$ along the initial curve $\Gamma = \{(1, y) : y \in \mathbb{R}\}$.

### 1. Parametrisation of the Cauchy curve and transversality

Parametrise the initial curve $\Gamma$ by $s \in \mathbb{R}$ (at characteristic parameter $t = 0$):
\[
x(0, s) = 1, \qquad y(0, s) = s, \qquad u(0, s) = s.
\]
Along $\Gamma$, the tangent vector to $\Gamma$ is $(x_s, y_s)|_{t=0} = (0, 1)$, while the characteristic vector field is $(x, x+y)|_{t=0} = (1, 1+s)$. The Jacobian on $\Gamma$ is
\[
J(0, s) = \left.\frac{\partial(x, y)}{\partial(t, s)}\right|_{t=0} = \det\begin{pmatrix} 1 & 0 \\ 1+s & 1 \end{pmatrix} = 1 \neq 0 \qquad \forall s \in \mathbb{R}.
\]
Thus $\Gamma$ is everywhere non-characteristic (transverse to the characteristics), guaranteeing a unique local $C^1$ solution in a neighbourhood of $x = 1$.

### 2. Characteristic equations and integration

Along a characteristic curve $(x(t, s), y(t, s))$ parametrised by $t \in \mathbb{R}$, the chain rule gives $\frac{du}{dt} = \frac{dx}{dt} u_x + \frac{dy}{dt} u_y$, so the PDE is equivalent to the characteristic ODE system
\[
\frac{dx}{dt} = x, \qquad \frac{dy}{dt} = x + y, \qquad \frac{du}{dt} = 1,
\]
subject to the initial conditions at $t = 0$:
\[
x(0, s) = 1, \qquad y(0, s) = s, \qquad u(0, s) = s.
\]

Solving sequentially:
1. From $\frac{dx}{dt} = x$ with $x(0, s) = 1$:
   \[
   x(t, s) = e^t.
   \]
2. Substituting $x = e^t$ into $\frac{dy}{dt} - y = e^t$ and multiplying by the integrating factor $e^{-t}$:
   \[
   \frac{d}{dt}\!\left(e^{-t} y\right) = 1 \implies e^{-t} y = t + C(s).
   \]
   Using $y(0, s) = s$ gives $C(s) = s$, so
   \[
   y(t, s) = (t + s) e^t.
   \]
3. From $\frac{du}{dt} = 1$ with $u(0, s) = s$:
   \[
   u(t, s) = t + s.
   \]

### 3. Inversion to $(x, y)$ coordinates and domain of validity

Check the Jacobian of the map $(t, s) \mapsto (x, y) = \big(e^t,\, (t+s)e^t\big)$:
\[
\frac{\partial(x, y)}{\partial(t, s)} = \det\begin{pmatrix} e^t & 0 \\ (t+s+1)e^t & e^t \end{pmatrix} = e^{2t} > 0 \qquad \forall (t, s) \in \mathbb{R}^2.
\]
As $(t, s)$ ranges over $\mathbb{R}^2$, the image $(x, y)$ covers the open right half-plane $\{(x, y) \in \mathbb{R}^2 : x > 0\}$ bijectively. Inverting explicitly for $x > 0$:
\[
t = \ln x, \qquad s = \frac{y}{e^t} - t = \frac{y}{x} - \ln x.
\]
Substituting into $u(t, s) = t + s$ (or observing directly that $y = (t+s)e^t = u x$):
\[
u(x, y) = \ln x + \left(\frac{y}{x} - \ln x\right) = \frac{y}{x}.
\]

### 4. Direct verification and domain remarks

Direct substitution of $u(x, y) = \dfrac{y}{x}$ confirms:
- Partial derivatives: $u_x = -\dfrac{y}{x^2}$ and $u_y = \dfrac{1}{x}$.
- PDE:
  \[
  x u_x + (x + y) u_y = x\left(-\frac{y}{x^2}\right) + (x + y)\left(\frac{1}{x}\right) = -\frac{y}{x} + 1 + \frac{y}{x} = 1.
  \]
- Cauchy data at $x = 1$: $u(1, y) = \dfrac{y}{1} = y$.

**Domain and uniqueness note:**
- On the half-plane $x > 0$ (swept out by the characteristics $y = x(\ln x + s)$ passing through $x = 1$), $u(x, y) = \frac{y}{x}$ is the **unique** $C^1$ solution satisfying $u(1, y) = y$.
- The line $x = 0$ is itself a characteristic curve (along $x = 0$, $dx/dt = 0$ and $dy/dt = y$), across which characteristics cannot pass, and $u(x, y) = y/x$ is singular along $x = 0$.
- Although $u(x, y) = y/x$ also satisfies the PDE for $x < 0$, the Cauchy data on $x = 1$ does **not** determine the solution uniquely on $x < 0$: any function of the form $u(x, y) = \frac{y}{x} + F\!\left(\frac{y}{x} - \ln(-x)\right)$ (for arbitrary $F \in C^1(\mathbb{R})$) solves the PDE on $x < 0$ because $\eta = \frac{y}{x} - \ln(-x)$ is constant along characteristics in $x < 0$.

## Final Answers

\[
u(x, y) = \frac{y}{x} \qquad (\text{unique } C^1 \text{ solution on } x > 0; \text{ also satisfies the PDE on } x < 0, \text{ singular at } x = 0).
\]
