## Full Solution

We consider the differential operator
\[
\mathcal{L}y = \frac{d^2 y}{dx^2} + 2\frac{dy}{dx}
\]
acting on real functions $y(x)$ on $0 \le x \le 1$.

### Part (i)

A general second-order linear differential equation
\[
p_0(x)y'' + p_1(x)y' + p_2(x)y = -\lambda y
\]
is cast into Sturm–Liouville form
\[
\tilde{\mathcal{L}}y \equiv \frac{d}{dx}\!\left(p(x)\frac{dy}{dx}\right) + q(x)y = -\lambda w(x)y
\]
by multiplying through by the integrating factor
\[
w(x) = \frac{1}{p_0(x)}\exp\!\left(\int \frac{p_1(x)}{p_0(x)}\,dx\right).
\]
Here $p_0(x) = 1$, $p_1(x) = 2$, and $p_2(x) = 0$, so taking the integrating factor $w(x) = e^{\int 2\,dx} = e^{2x}$ (canonical choice of positive multiplicative constant $1$) and multiplying $\mathcal{L}y = -\lambda y$ by $e^{2x}$ gives
\[
e^{2x}\frac{d^2 y}{dx^2} + 2e^{2x}\frac{dy}{dx} = -\lambda e^{2x} y.
\]
By the product rule, the left-hand side is $\frac{d}{dx}\!\left(e^{2x}\frac{dy}{dx}\right)$. Hence the Sturm–Liouville form $\tilde{\mathcal{L}}y = -\lambda w y$ is
\[
\frac{d}{dx}\!\left(e^{2x}\frac{dy}{dx}\right) = -\lambda e^{2x} y,
\]
with Sturm–Liouville operator and weight function
\[
\tilde{\mathcal{L}}y = \frac{d}{dx}\!\left(e^{2x}\frac{dy}{dx}\right) \qquad \bigl(p(x) = e^{2x},\ q(x) = 0\bigr), \qquad w(x) = e^{2x}.
\]
(Note that any constant positive multiple $C e^{2x}$ for both $p$ and $w$ gives an equivalent Sturm–Liouville form; $C = 1$ is standard. Since $p(x) > 0$ and $w(x) > 0$ are smooth on $[0, 1]$, this is a regular Sturm–Liouville problem.)

### Part (ii)

We impose the homogeneous Dirichlet boundary conditions $y(0) = y(1) = 0$ on the eigenvalue equation
\[
y'' + 2y' + \lambda y = 0, \qquad 0 \le x \le 1.
\]

**Step 1: Reality (and positivity) of eigenvalues.**
Even if we temporarily allow complex eigenfunctions $y \not\equiv 0$ and complex $\lambda$, multiplying $\tilde{\mathcal{L}}y = -\lambda w y$ by $y^*(x)$, integrating over $[0, 1]$, and integrating by parts gives
\[
-\lambda \int_0^1 e^{2x}|y(x)|^2\,dx = \int_0^1 y^*(x)\frac{d}{dx}\!\left(e^{2x}y'(x)\right)dx = \Big[y^*(x)e^{2x}y'(x)\Big]_0^1 - \int_0^1 e^{2x}|y'(x)|^2\,dx = -\int_0^1 e^{2x}|y'(x)|^2\,dx,
\]
where the boundary term vanishes because $y(0) = y(1) = 0$. Since $e^{2x} > 0$ and $y \not\equiv 0$, $\int_0^1 e^{2x}|y(x)|^2\,dx > 0$, so
\[
\lambda = \frac{\int_0^1 e^{2x}|y'(x)|^2\,dx}{\int_0^1 e^{2x}|y(x)|^2\,dx} \in \mathbb{R}, \qquad \lambda \ge 0.
\]
(Moreover $\lambda = 0$ would force $y' \equiv 0$, hence $y$ constant, and $y(0) = 0$ then forces $y \equiv 0$; thus $\lambda > 0$.)

**Step 2: Solving the ODE across all real $\lambda$.**
The auxiliary equation for $y'' + 2y' + \lambda y = 0$ is
\[
m^2 + 2m + \lambda = 0 \implies m = -1 \pm \sqrt{1 - \lambda}.
\]
We examine the three exhaustive cases for $\lambda \in \mathbb{R}$:

1. **$\lambda < 1$:** Write $\mu = \sqrt{1 - \lambda} > 0$. Then $m = -1 \pm \mu$ are distinct real roots, so the general real solution is
   \[
   y(x) = e^{-x}\bigl(A\cosh(\mu x) + B\sinh(\mu x)\bigr).
   \]
   Imposing $y(0) = 0$ yields $A = 0$. Then $y(1) = B e^{-1}\sinh\mu = 0$. Since $\mu > 0$, $\sinh\mu > 0$, forcing $B = 0$ and hence the trivial solution $y \equiv 0$. Thus there are **no eigenvalues** with $\lambda < 1$.

2. **$\lambda = 1$:** Repeated root $m = -1$, so the general solution is
   \[
   y(x) = (A + Bx)e^{-x}.
   \]
   Imposing $y(0) = 0$ gives $A = 0$, and then $y(1) = B e^{-1} = 0$ gives $B = 0$, again yielding only $y \equiv 0$. Thus $\lambda = 1$ is **not an eigenvalue**.

3. **$\lambda > 1$:** Write $k = \sqrt{\lambda - 1} > 0$. Then $m = -1 \pm ik$, so the general real solution is
   \[
   y(x) = e^{-x}\bigl(A\cos(kx) + B\sin(kx)\bigr).
   \]
   Imposing $y(0) = 0$ gives $A = 0$, so $y(x) = B e^{-x}\sin(kx)$. Imposing $y(1) = 0$ gives
   \[
   B e^{-1}\sin k = 0.
   \]
   For a non-trivial eigenfunction ($B \ne 0$), we require $\sin k = 0$. Since $k > 0$, this holds if and only if
   \[
   k = n\pi, \qquad n = 1, 2, 3, \dots
   \]
   (Negative integers $k = -n\pi$ give the same values of $\lambda = 1 + k^2$ and linearly dependent eigenfunctions $-\sin(n\pi x)$.)

Hence the eigenvalues are
\[
\lambda_n = 1 + n^2\pi^2, \qquad n = 1, 2, 3, \dots
\]
Since $n \mapsto 1 + n^2\pi^2$ is strictly increasing on $\mathbb{Z}_{>0}$, the eigenvalues form an infinite discrete set
\[
\lambda_1 < \lambda_2 < \lambda_3 < \dots \qquad (\text{with } \lambda_1 = 1 + \pi^2,\ \lambda_2 = 1 + 4\pi^2,\ \dots).
\]
The corresponding eigenfunctions (unique up to a non-zero multiplicative constant) are
\[
y_n(x) = e^{-x}\sin(n\pi x), \qquad n = 1, 2, 3, \dots
\]

**Step 3: Orthogonality and eigenfunction expansion of $f(x) = x - x^2$.**
For any two eigenfunctions $y_m, y_n$ corresponding to distinct eigenvalues $\lambda_m \ne \lambda_n$, Sturm–Liouville self-adjointness gives
\[
(\lambda_m - \lambda_n)\int_0^1 w(x) y_m(x) y_n(x)\,dx = \int_0^1 \bigl(y_m\tilde{\mathcal{L}}y_n - y_n\tilde{\mathcal{L}}y_m\bigr)\,dx = \Big[e^{2x}\bigl(y_m y_n' - y_n y_m'\bigr)\Big]_0^1 = 0,
\]
since $y_m$ and $y_n$ vanish at $x = 0$ and $x = 1$. Therefore the eigenfunctions are orthogonal with respect to the weight $w(x) = e^{2x}$:
\[
\int_0^1 e^{2x} y_m(x) y_n(x)\,dx = 0 \qquad (m \ne n).
\]
(Directly, $\int_0^1 e^{2x} y_m(x) y_n(x)\,dx = \int_0^1 \sin(m\pi x)\sin(n\pi x)\,dx = \frac{1}{2}\delta_{mn}$.)

Now expand $f(x) = x - x^2$ on $0 \le x \le 1$ as
\[
f(x) = \sum_{n=1}^\infty A_n y_n(x).
\]
Multiplying both sides by $w(x) y_m(x) = e^{2x} y_m(x)$ and integrating from $0$ to $1$ (valid term-by-term since $f$ is smooth on $[0, 1]$ and satisfies $f(0) = f(1) = 0$, so $e^x f(x)$ has a uniformly convergent Fourier sine series):
\[
\int_0^1 w(x) f(x) y_m(x)\,dx = \sum_{n=1}^\infty A_n \int_0^1 w(x) y_n(x) y_m(x)\,dx = A_m \int_0^1 w(x)[y_m(x)]^2\,dx.
\]
Relabelling $m \to n$, the expansion coefficients are
\[
A_n = \frac{\int_0^1 w(x) f(x) y_n(x)\,dx}{\int_0^1 w(x)[y_n(x)]^2\,dx}
= \frac{\int_0^1 e^{2x}(x - x^2) e^{-x}\sin(n\pi x)\,dx}{\int_0^1 e^{2x} e^{-2x}\sin^2(n\pi x)\,dx}
= \frac{\int_0^1 (x - x^2)e^x\sin(n\pi x)\,dx}{\int_0^1 \sin^2(n\pi x)\,dx}.
\]
Since $\int_0^1 \sin^2(n\pi x)\,dx = \frac{1}{2}$ for all integers $n \ge 1$, this simplifies cleanly to
\[
A_n = 2\int_0^1 (x - x^2)e^x\sin(n\pi x)\,dx.
\]
(Note: if one instead normalises the eigenfunctions to $\hat{y}_n(x) = \sqrt{2}\,e^{-x}\sin(n\pi x)$ so that $\int_0^1 w\hat{y}_n^2\,dx = 1$, then $\hat{A}_n = \sqrt{2}\int_0^1 (x - x^2)e^x\sin(n\pi x)\,dx$, and $\hat{A}_n\hat{y}_n(x) = A_n y_n(x)$ is identical.)

## Final Answers

- **(i)** $\tilde{\mathcal{L}}y = \dfrac{d}{dx}\!\left(e^{2x}\dfrac{dy}{dx}\right)$ and $w(x) = e^{2x}$ (up to a common positive constant multiple).
- **(ii)**
  - Eigenvalues: $\lambda_n = 1 + n^2\pi^2$ for $n = 1, 2, 3, \dots$ (strictly increasing: $\lambda_1 < \lambda_2 < \dots$, infinite discrete set).
  - Eigenfunctions: $y_n(x) = e^{-x}\sin(n\pi x)$ for $n = 1, 2, 3, \dots$ (up to non-zero scalar multiples).
  - Expansion coefficients for $f(x) = x - x^2 = \sum_{n=1}^\infty A_n y_n(x)$ (with $y_n(x) = e^{-x}\sin(n\pi x)$):
    \[
    A_n = \frac{\int_0^1 (x - x^2)e^x\sin(n\pi x)\,dx}{\int_0^1 \sin^2(n\pi x)\,dx} = 2\int_0^1 (x - x^2)e^x\sin(n\pi x)\,dx.
    \]
