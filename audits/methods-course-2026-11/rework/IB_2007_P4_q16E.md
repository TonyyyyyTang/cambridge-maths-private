## Full Solution

### 1. Euler–Lagrange equation and Beltrami first integral

For the functional
\[I[y] = \int_a^b F(y, y')\,dx,\]
where $y' = dy/dx$ and $F$ has no explicit dependence on $x$, the Euler–Lagrange equation for extrema is
\[\frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right) - \frac{\partial F}{\partial y} = 0.\]

**Derivation of the first integral:**
Since $F = F(y, y')$ does not depend explicitly on $x$, the chain rule gives
\[\frac{dF}{dx} = \frac{\partial F}{\partial y}y' + \frac{\partial F}{\partial y'}y''.\]
Differentiating $F - y'\frac{\partial F}{\partial y'}$ with respect to $x$ using the product rule yields
\begin{align*}
\frac{d}{dx}\left(F - y'\frac{\partial F}{\partial y'}\right)
&= \left(\frac{\partial F}{\partial y}y' + \frac{\partial F}{\partial y'}y''\right) - y''\frac{\partial F}{\partial y'} - y'\frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right) \\
&= y'\left[\frac{\partial F}{\partial y} - \frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right)\right] = 0
\end{align*}
along any solution of the Euler–Lagrange equation. Integrating once gives the first integral
\[F - y'\frac{\partial F}{\partial y'} = C,\]
where $C$ is a constant.

---

### 2. Integral expression for total travel time $T$

Let $r = r(\theta)$ describe the road from $A = (a, 0)$ to $B = (a, \pi/2)$ in polar coordinates (with $a > 0$, $r(\theta) > 0$ on $[0, \pi/2]$, and $r(0) = r(\pi/2) = a$). Denote $r' = \frac{dr}{d\theta}$.

Using $ds^2 = dr^2 + r^2\,d\theta^2$, the arc-length element as $\theta$ increases from $0$ to $\pi/2$ is
\[ds = \sqrt{r'^2 + r^2}\,d\theta.\]
With speed $v = k r^2$ ($k > 0$), the travel time element is $dt = ds/v = \frac{\sqrt{r'^2 + r^2}}{k r^2}\,d\theta$, so the total travel time from $A$ to $B$ is
\[T[r] = \int_0^{\pi/2} \frac{\sqrt{r'^2 + r^2}}{k r^2}\,d\theta = \frac{1}{k}\int_0^{\pi/2} \frac{\sqrt{r'^2 + r^2}}{r^2}\,d\theta.\]

---

### 3. Travel time for the circular road $r = a$

Setting $r(\theta) = a$ gives $r'(\theta) = 0$, so
\[T_{\text{circ}} = \frac{1}{k}\int_0^{\pi/2} \frac{\sqrt{0 + a^2}}{a^2}\,d\theta = \frac{1}{k}\int_0^{\pi/2} \frac{1}{a}\,d\theta = \frac{\pi}{2ka}.\]

---

### 4. Road minimising $T$ and minimum travel time

The integrand is
\[F(r, r') = \frac{\sqrt{r'^2 + r^2}}{k r^2},\]
which does not depend explicitly on the independent variable $\theta$. Therefore any extremal satisfies the first integral $F - r'\frac{\partial F}{\partial r'} = C$.

Computing $\frac{\partial F}{\partial r'}$:
\[\frac{\partial F}{\partial r'} = \frac{r'}{k r^2 \sqrt{r'^2 + r^2}}.\]
Hence
\[F - r'\frac{\partial F}{\partial r'} = \frac{\sqrt{r'^2 + r^2}}{k r^2} - \frac{r'^2}{k r^2 \sqrt{r'^2 + r^2}} = \frac{(r'^2 + r^2) - r'^2}{k r^2 \sqrt{r'^2 + r^2}} = \frac{1}{k\sqrt{r'^2 + r^2}} = C.\]
Since $k > 0$ and $\sqrt{r'^2 + r^2} > 0$, we must have $C > 0$. Setting $R = \frac{1}{kC} > 0$ gives
\[r'^2 + r^2 = R^2.\]

Note that the singular constant solution $r(\theta) \equiv R$ does **not** satisfy the Euler–Lagrange equation (since when $r' \equiv 0$, $\frac{d}{d\theta}\frac{\partial F}{\partial r'} = 0$ whereas $\frac{\partial F}{\partial r} = -\frac{1}{k r^2} \neq 0$; the factor $r'$ in $r'(F_r - \frac{d}{d\theta}F_{r'}) = 0$ introduces this spurious constant solution). Indeed, differentiating $r'^2 + r^2 = R^2$ gives $2r'(r'' + r) = 0$, and direct evaluation of the full Euler–Lagrange equation simplifies identically for $r > 0$ to
\[\frac{r'' + r}{k(r'^2 + r^2)^{3/2}} = 0 \iff r'' + r = 0.\]
(Alternatively, separating variables in $\frac{dr}{d\theta} = \pm\sqrt{R^2 - r^2}$ on intervals where $r < R$ yields $r(\theta) = R\cos(\theta - \theta_0)$.)

The general non-constant solution of $r'^2 + r^2 = R^2$ (and of $r'' + r = 0$) is therefore
\[r(\theta) = R\cos(\theta - \theta_0).\]

**Applying the boundary conditions $r(0) = a$ and $r(\pi/2) = a$:**
\begin{align*}
r(0) = a &\implies R\cos\theta_0 = a, \\
r(\pi/2) = a &\implies R\cos\left(\frac{\pi}{2} - \theta_0\right) = R\sin\theta_0 = a.
\end{align*}
Since $a > 0$ and $R > 0$, we need $\cos\theta_0 = \sin\theta_0 > 0$, which (requiring $r(\theta) > 0$ throughout $[0, \pi/2]$) uniquely fixes $\theta_0 = \frac{\pi}{4}$ (modulo $2\pi$) and
\[R = \frac{a}{\cos(\pi/4)} = \sqrt{2}\,a.\]
Therefore the optimal road has polar equation
\[r(\theta) = \sqrt{2}\,a\cos\left(\theta - \frac{\pi}{4}\right) = a(\cos\theta + \sin\theta), \qquad 0 \leqslant \theta \leqslant \frac{\pi}{2}.\]
*(Geometrically, multiplying by $r$ gives $x^2 + y^2 = ax + ay$, i.e. $(x - a/2)^2 + (y - a/2)^2 = a^2/2$, the outer arc of the circle through the origin, $A$, and $B$.)*

**Minimum travel time:**
Along $r(\theta) = R\cos(\theta - \pi/4)$ we have $\sqrt{r'^2 + r^2} = R = \sqrt{2}\,a$, so
\begin{align*}
T_{\min}
&= \frac{1}{k}\int_0^{\pi/2} \frac{R}{R^2 \cos^2(\theta - \pi/4)}\,d\theta
= \frac{1}{kR}\int_0^{\pi/2} \sec^2\left(\theta - \frac{\pi}{4}\right)d\theta \\
&= \frac{1}{k\sqrt{2}\,a}\left[\tan\left(\theta - \frac{\pi}{4}\right)\right]_0^{\pi/2}
= \frac{1}{k\sqrt{2}\,a}\bigl(1 - (-1)\bigr)
= \frac{\sqrt{2}}{ka}.
\end{align*}
Note that $T_{\min} = \frac{\sqrt{2}}{ka} < \frac{\pi}{2ka} = T_{\text{circ}}$ (since $\sqrt{2} \approx 1.414 < 1.571 \approx \pi/2$).

**Verification that this extremal is the strict global minimum:**
Define $u(\theta) = \frac{\cos\theta}{r(\theta)}$ and $v(\theta) = -\frac{\sin\theta}{r(\theta)}$ (corresponding to complex inversion $w = u + iv = 1/z$). Direct differentiation gives
\[u'^2 + v'^2 = \frac{(-r\sin\theta - r'\cos\theta)^2 + (-r\cos\theta + r'\sin\theta)^2}{r^4} = \frac{r'^2 + r^2}{r^4}.\]
Thus for any piecewise $C^1$ path $r(\theta) > 0$ from $(a, 0)$ to $(a, \pi/2)$, the triangle inequality for plane curves (or Cauchy–Schwarz) gives
\[T[r] = \frac{1}{k}\int_0^{\pi/2} \sqrt{u'^2 + v'^2}\,d\theta \geqslant \frac{1}{k}\sqrt{\bigl(u(\pi/2) - u(0)\bigr)^2 + \bigl(v(\pi/2) - v(0)\bigr)^2} = \frac{1}{k}\sqrt{\left(-\frac{1}{a}\right)^2 + \left(-\frac{1}{a}\right)^2} = \frac{\sqrt{2}}{ka},\]
with equality if and only if $(u(\theta), v(\theta))$ traverses the straight line segment from $(1/a, 0)$ to $(0, -1/a)$, i.e. $u(\theta) - v(\theta) = \frac{1}{a} \iff r(\theta) = a(\cos\theta + \sin\theta)$. Hence $T_{\min} = \frac{\sqrt{2}}{ka}$ is indeed the unique global minimum.

## Final Answers

- **Euler–Lagrange equation:** $\dfrac{d}{dx}\!\left(\dfrac{\partial F}{\partial y'}\right) - \dfrac{\partial F}{\partial y} = 0$, with first integral $F - y'\dfrac{\partial F}{\partial y'} = C$.
- **Travel-time integral:** $T = \dfrac{1}{k}\displaystyle\int_0^{\pi/2} \frac{\sqrt{r'^2 + r^2}}{r^2}\,d\theta$ (where $r' = dr/d\theta$).
- **Circular road $r = a$:** $T = \dfrac{\pi}{2ka}$.
- **Optimal road:** $r(\theta) = \sqrt{2}\,a\cos\!\left(\theta - \dfrac{\pi}{4}\right) = a(\cos\theta + \sin\theta)$ for $0 \leqslant \theta \leqslant \dfrac{\pi}{2}$.
- **Minimum travel time:** $T_{\min} = \dfrac{\sqrt{2}}{ka}$.
