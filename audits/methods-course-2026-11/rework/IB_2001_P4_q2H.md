## Full Solution

### 1. Deriving the ODE for $R_n(x) = P_n'(x)$

The Legendre polynomial $P_n(x)$ satisfies
\[
(1 - x^2) P_n''(x) - 2x P_n'(x) + n(n+1) P_n(x) = 0, \qquad n = 0, 1, \ldots,\quad -1 \leqslant x \leqslant 1.
\]
Since $P_n(x)$ is a polynomial (hence smooth everywhere), we differentiate this equation once with respect to $x$:
\[
\frac{\mathrm{d}}{\mathrm{d}x}\!\bigl[(1 - x^2) P_n''(x)\bigr] - \frac{\mathrm{d}}{\mathrm{d}x}\!\bigl[2x P_n'(x)\bigr] + n(n+1) P_n'(x) = 0.
\]
Expanding via the product rule gives
\[
(1 - x^2) P_n'''(x) - 2x P_n''(x) - 2x P_n''(x) - 2 P_n'(x) + n(n+1) P_n'(x) = 0,
\]
that is,
\[
(1 - x^2) P_n'''(x) - 4x P_n''(x) + \bigl[n(n+1) - 2\bigr] P_n'(x) = 0.
\]
Factorising the coefficient of $P_n'(x)$,
\[
n(n+1) - 2 = n^2 + n - 2 = (n - 1)(n + 2),
\]
and substituting $R_n(x) = P_n'(x)$ (so $R_n' = P_n''$ and $R_n'' = P_n'''$), we obtain the second-order linear ODE
\[
(1 - x^2) R_n''(x) - 4x R_n'(x) + (n - 1)(n + 2) R_n(x) = 0, \qquad -1 \leqslant x \leqslant 1.
\]

*(Edge-case note: For $n = 0$, $P_0(x) = 1$, so $R_0(x) = P_0'(x) \equiv 0$, which satisfies the ODE trivially but is not a non-trivial eigenfunction. For every $n \geqslant 1$, $P_n(x)$ has exact degree $n \geqslant 1$, so $R_n(x) = P_n'(x)$ is a non-zero polynomial of exact degree $n - 1$, giving genuine eigenfunctions for $n = 1, 2, 3, \ldots$ with eigenvalues $\lambda_n = (n-1)(n+2) \geqslant 0$, starting at $\lambda_1 = 0$ for $R_1(x) = 1$.)*

### 2. Recasting in Sturm–Liouville Form

To recast a second-order linear ODE of the form $a(x) y'' + b(x) y' + [c(x) + \lambda d(x)] y = 0$ into Sturm–Liouville form
\[
\frac{\mathrm{d}}{\mathrm{d}x}\!\bigl(p(x) y'\bigr) + \bigl[q(x) + \lambda w(x)\bigr] y = 0,
\]
we require an integrating factor $\mu(x) > 0$ on $(-1, 1)$ such that $p(x) = \mu(x) a(x)$ satisfies $p'(x) = \mu(x) b(x)$, i.e.
\[
\frac{p'(x)}{p(x)} = \frac{b(x)}{a(x)}.
\]
Here $a(x) = 1 - x^2$, $b(x) = -4x$, $c(x) = 0$, $d(x) = 1$, and $\lambda = \lambda_n = (n-1)(n+2)$. Therefore, on $(-1, 1)$:
\[
\frac{p'(x)}{p(x)} = \frac{-4x}{1 - x^2} = 2\,\frac{\mathrm{d}}{\mathrm{d}x}\ln(1 - x^2)
\implies p(x) = (1 - x^2)^2
\]
(choosing the positive constant of integration equal to $1$), which corresponds to the integrating factor
\[
\mu(x) = \frac{p(x)}{a(x)} = 1 - x^2.
\]
Multiplying the ODE for $R_n(x)$ through by $\mu(x) = 1 - x^2$:
\[
(1 - x^2)^2 R_n''(x) - 4x(1 - x^2) R_n'(x) + (n - 1)(n + 2)(1 - x^2) R_n(x) = 0.
\]
Since $\dfrac{\mathrm{d}}{\mathrm{d}x}\bigl[(1 - x^2)^2\bigr] = -4x(1 - x^2)$, the first two terms combine into a single derivative, yielding the Sturm–Liouville form:
\[
\frac{\mathrm{d}}{\mathrm{d}x}\!\Bigl[(1 - x^2)^2 R_n'(x)\Bigr] + (n - 1)(n + 2)(1 - x^2) R_n(x) = 0, \qquad -1 \leqslant x \leqslant 1.
\]
This is a (singular) Sturm–Liouville eigenvalue equation with:
- $p(x) = (1 - x^2)^2$ (positive on $(-1,1)$ and vanishing at $x = \pm 1$),
- $q(x) = 0$,
- weight function $w(x) = 1 - x^2$ (positive on $(-1,1)$),
- eigenvalue $\lambda_n = (n - 1)(n + 2)$.

### 3. Orthogonality Relation for $R_n(x), R_m(x)$ ($n \neq m$)

Write the Sturm–Liouville equations for $R_n$ and $R_m$ ($n, m \in \{0, 1, 2, \ldots\}$, $n \neq m$):
\[
\frac{\mathrm{d}}{\mathrm{d}x}\!\bigl[(1 - x^2)^2 R_n'\bigr] + \lambda_n (1 - x^2) R_n = 0,
\]
\[
\frac{\mathrm{d}}{\mathrm{d}x}\!\bigl[(1 - x^2)^2 R_m'\bigr] + \lambda_m (1 - x^2) R_m = 0.
\]
Multiply the first equation by $R_m(x)$, the second by $R_n(x)$, and subtract:
\[
R_m \frac{\mathrm{d}}{\mathrm{d}x}\!\bigl[(1 - x^2)^2 R_n'\bigr] - R_n \frac{\mathrm{d}}{\mathrm{d}x}\!\bigl[(1 - x^2)^2 R_m'\bigr] + (\lambda_n - \lambda_m)(1 - x^2) R_n R_m = 0.
\]
By the product rule (Lagrange's identity), the first two terms form an exact derivative:
\[
\frac{\mathrm{d}}{\mathrm{d}x}\!\Bigl[(1 - x^2)^2 \bigl(R_m R_n' - R_n R_m'\bigr)\Bigr] + (\lambda_n - \lambda_m)(1 - x^2) R_n R_m = 0.
\]
Integrating from $x = -1$ to $x = 1$:
\[
\Bigl[(1 - x^2)^2 \bigl(R_m(x) R_n'(x) - R_n(x) R_m'(x)\bigr)\Bigr]_{-1}^{1} + (\lambda_n - \lambda_m) \int_{-1}^{1} (1 - x^2) R_n(x) R_m(x)\,\mathrm{d}x = 0.
\]
Because $R_n, R_m, R_n', R_m'$ are polynomials, they are finite at both endpoints $x = \pm 1$, while $p(\pm 1) = (1 - (\pm 1)^2)^2 = 0$. Therefore the boundary term vanishes identically:
\[
\Bigl[(1 - x^2)^2 \bigl(R_m(x) R_n'(x) - R_n(x) R_m'(x)\bigr)\Bigr]_{-1}^{1} = 0.
\]
This leaves
\[
(\lambda_n - \lambda_m) \int_{-1}^{1} (1 - x^2) R_n(x) R_m(x)\,\mathrm{d}x = 0.
\]
Finally, check that the eigenvalues are distinct for all non-negative integers $n \neq m$:
\[
\lambda_n - \lambda_m = (n^2 + n - 2) - (m^2 + m - 2) = (n - m)(n + m + 1) \neq 0,
\]
since $n \neq m$ and $n + m + 1 \geqslant 1 > 0$. Dividing by $\lambda_n - \lambda_m$ yields the orthogonality relation:
\[
\int_{-1}^{1} (1 - x^2) R_n(x) R_m(x)\,\mathrm{d}x = 0 \qquad (n \neq m).
\]
*(Cross-check: integrating by parts directly using Legendre's equation gives $\int_{-1}^{1} (1-x^2) P_n' P_m'\,\mathrm{d}x = [(1-x^2)P_n' P_m]_{-1}^{1} - \int_{-1}^{1}[(1-x^2)P_n']' P_m\,\mathrm{d}x = n(n+1)\int_{-1}^{1} P_n P_m\,\mathrm{d}x = \frac{2n(n+1)}{2n+1}\delta_{nm}$, confirming both orthogonality with weight $w(x) = 1 - x^2$ for $n \neq m$ and the normalisation for $n = m$.)*
