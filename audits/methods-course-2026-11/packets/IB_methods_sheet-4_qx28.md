## Question (verbatim question.tex)
```latex
\emph{Symmetry.}

Consider a Dirichlet Green’s function $G(\mathbf{r};\mathbf{r}_0)$ for the Laplacian defined in an arbitrary three-dimensional domain $\mathcal{D}$. By using Green’s second identity, show that $G(\mathbf{r};\mathbf{r}_0)=G(\mathbf{r}_0;\mathbf{r})$ for all $\mathbf{r}\ne\mathbf{r}_0$ in the domain $\mathcal{D}$.
```
