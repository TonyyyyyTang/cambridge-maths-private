## Question (verbatim question.tex)
```latex
Recall from lectures that if $y_\alpha(r)=J_m(\alpha r)$, where $J_m$ is the $m$th order Bessel function of the 1st kind, then
\[
-\frac{\mathrm d}{\mathrm dr}\left(r\frac{\mathrm dy_\alpha}{\mathrm dr}\right)+\frac{m^2}{r}y_\alpha=\alpha^2 r y_\alpha,\qquad r\in(0,1).
\]
Show that if $y_\beta(r)=J_m(\beta r)$ then $[r(y_\alpha y_\beta'-y_\beta y_\alpha')]'=(\alpha^2-\beta^2)ry_\alpha y_\beta$. Deduce that
\[
\int_0^1J_m(\alpha r)J_m(\beta r)r\,\mathrm dr
=\frac{\beta J_m(\alpha)J_m'(\beta)-\alpha J_m(\beta)J_m'(\alpha)}{\alpha^2-\beta^2},
\qquad\alpha\ne\beta.
\]
Use this result to show that
\[
\int_0^1J_m(j_{mk}r)J_m(j_{m\ell}r)r\,\mathrm dr
=\tfrac12[J_m'(j_{mk})]^2\delta_{k\ell},
\]
where $J_m(j_{mk})=0$, $k=1,2,\ldots$.
```
