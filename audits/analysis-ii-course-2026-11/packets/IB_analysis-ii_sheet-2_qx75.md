## Question (verbatim question.tex)
```latex
Show that a set $I\subset\mathbb R$ is path-connected if and only if $I$ is an interval.

\emph{[An interval is a set taking one of the forms $(-\infty,\infty)$, $(-\infty,b)$, $(-\infty,b]$, $[a,\infty)$, $(a,\infty)$, $[a,b]$, $[a,b)$, $(a,b]$ or $(a,b)$ for some $a,b\in\mathbb R$ with $a\le b$. In particular, the empty set is an interval and each one-point set is an interval.]}
```
