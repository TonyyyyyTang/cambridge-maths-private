## Question (verbatim question.tex)
```latex
$^*$ Suppose $C$ is a sequentially compact subset of a normed space $V$. If $\{U_\alpha\mid\alpha\in A\}$ is a family of open subsets of $V$, we say that the $U_\alpha$ cover $C$ if $C\subset\cup_{\alpha\in A}U_\alpha$.

(a) Given $\epsilon>0$, show that there is a finite set of points $\{\mathbf v_1,\ldots,\mathbf v_n\}\subset C$ such that $\{B_\epsilon(\mathbf v_1),\ldots,B_\epsilon(\mathbf v_n)\}$ cover $C$.

(b) Show that there exists some $\epsilon>0$ such that for every $\mathbf v\in C$, $B_\epsilon(\mathbf v)\subset U_\alpha$ for some $\alpha$. Deduce that there is a finite set $\{\alpha_1,\ldots,\alpha_n\}\subset A$ such that $\{U_{\alpha_1},\ldots,U_{\alpha_n}\}$ cover $C$.
```
