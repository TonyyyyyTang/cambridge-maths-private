## Question (verbatim question.tex)
```latex
Suppose that for each $n=1,2,\ldots$, the function $f_n:\R\to\R$ is uniformly continuous on $\R$.
\begin{enumerate}
\item[(a)] If $f_n\to f$ pointwise on $\R$ is $f$ necessarily continuous on $\R$?
\item[(b)] If $f_n\to f$ uniformly on $\R$ is $f$ necessarily continuous on $\R$?
\end{enumerate}
In each case, give a proof or a counter-example (with justification).
```
