## Question (verbatim question.tex)
```latex
Show that if $(f_n)$ is a sequence of uniformly continuous, real-valued functions on $\R$, and if $f_n\to f$ uniformly, then $f$ is uniformly continuous. Give an example of a sequence of uniformly continuous, real-valued functions $(f_n)$ on $\R$ such that $f_n$ converges pointwise to a function $f$ which is continuous but not uniformly continuous.
```
