## Question (verbatim question.tex)
```latex
Let $a<b$ and $R>0$ be real numbers, let $y_0\in\mathbb R^n$ and let $\varphi:[a,b]\times B_R(y_0)\to\mathbb R^n$ be a continuous function. Assume that for some $K\ge0$ we have $\|\varphi(t,x)-\varphi(t,y)\|\le K\|x-y\|$ for all $t\in[a,b]$ and all $x,y\in B_R(y_0)$. Assume further that
\[
\sup\{\|\varphi(t,x)\|:t\in[a,b],\ x\in B_R(y_0)\}\le\frac{R}{b-a}.
\]
Using the first part of the previous question, show that for any $t_0\in[a,b]$, the initial value problem
\[
f'(t)=\varphi(t,f(t)),\qquad f(t_0)=y_0
\]
has a unique solution on $[a,b]$.
```
