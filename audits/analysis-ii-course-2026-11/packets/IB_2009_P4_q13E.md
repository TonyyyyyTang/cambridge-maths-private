## Question (verbatim question.tex)
```latex
Let $(X,d)$ be a metric space with at least two points. If $f:X\to\mathbb R$ is a function, write
\[\operatorname{Lip}(f)=\sup_{x\neq y}\frac{|f(x)-f(y)|}{d(x,y)}+\sup_z|f(z)|,\]
provided that this supremum is finite. Let $\operatorname{Lip}(X)=\{f:\operatorname{Lip}(f)\text{ is defined}\}$. Show that $\operatorname{Lip}(X)$ is a vector space over $\mathbb R$, and that $\operatorname{Lip}$ is a norm on it.

Now let $X=\mathbb R$. Suppose that $(f_i)_{i=1}^\infty$ is a sequence of functions with $\operatorname{Lip}(f_i)\leqslant1$ and with the property that the sequence $f_i(q)$ converges as $i\to\infty$ for every rational number $q$. Show that the $f_i$ converge pointwise to a function $f$ satisfying $\operatorname{Lip}(f)\leqslant1$.

Suppose now that $(f_i)_{i=1}^\infty$ are any functions with $\operatorname{Lip}(f_i)\leqslant1$. Show that there is a subsequence $f_{i_1},f_{i_2},\ldots$ which converges pointwise to a function $f$ with $\operatorname{Lip}(f)\leqslant1$.
```
