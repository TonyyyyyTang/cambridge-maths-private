## Question (verbatim question.tex)
```latex
\begin{enumerate}
\item[(a)] Let $A\subset\mathbb{R}^m$ and let $f,f_n:A\to\mathbb{R}$ be functions for $n=1,2,3,\ldots$. What does it mean to say that the sequence $(f_n)$ \emph{converges uniformly to $f$ on $A$}? What does it mean to say that $f$ is \emph{uniformly continuous}?
\item[(b)] Let $f:\mathbb{R}\to\mathbb{R}$ be a uniformly continuous function. Determine whether each of the following statements is true or false. Give reasons for your answers.
\begin{enumerate}
\item[(i)] If $f_n(x)=f(x+1/n)$ for each $n=1,2,3,\ldots$ and each $x\in\mathbb{R}$, then $f_n\to f$ uniformly on $\mathbb{R}$.
\item[(ii)] If $g_n(x)=(f(x+1/n))^2$ for each $n=1,2,3,\ldots$ and each $x\in\mathbb{R}$, then $g_n\to(f)^2$ uniformly on $\mathbb{R}$.
\end{enumerate}
\item[(c)] Let $A$ be a closed, bounded subset of $\mathbb{R}^m$. For each $n=1,2,3,\ldots$, let $g_n:A\to\mathbb{R}$ be a continuous function such that $(g_n(x))$ is a decreasing sequence for each $x\in A$. If $\delta\in\mathbb{R}$ is such that for each $n$ there is $x_n\in A$ with $g_n(x_n)\geq\delta$, show that there is $x_0\in A$ such that $\lim_{n\to\infty}g_n(x_0)\geq\delta$.

Deduce the following: If $f_n:A\to\mathbb{R}$ is a continuous function for each $n=1,2,3,\ldots$ such that $(f_n(x))$ is a decreasing sequence for each $x\in A$, and if the pointwise limit of $(f_n)$ is a continuous function $f:A\to\mathbb{R}$, then $f_n\to f$ uniformly on $A$.
\end{enumerate}
```
