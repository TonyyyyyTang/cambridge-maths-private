## Question (verbatim question.tex)
```latex
Show that each of the functions below is a metric on the set of functions $x(t)\in C[a,b]$:
\[
\begin{aligned}
d_1(x,y)&=\sup_{t\in[a,b]}|x(t)-y(t)|,\\
d_2(x,y)&=\bigl\{\textstyle\int_a^b|x(t)-y(t)|^2dt\}^{1/2}.
\end{aligned}
\]
Is the space complete in the $d_1$ metric? Justify your answer.

Show that the set of functions
\[
x_n(t)=\Biggl\{\begin{aligned}&0,&&-1\leqslant t<0\\[-2pt]&nt,&&0\leqslant t<1/n\\[-2pt]&1,&&1/n\leqslant t\leqslant 1\end{aligned}
\]
is a Cauchy sequence with respect to the $d_2$ metric on $C[-1,1]$, yet does not tend to a limit in the $d_2$ metric in this space. Hence, deduce that this space is not complete in the $d_2$ metric.
```
