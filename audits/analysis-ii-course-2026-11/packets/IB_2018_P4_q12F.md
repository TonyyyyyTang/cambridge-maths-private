## Question (verbatim question.tex)
```latex
\begin{enumerate}
\item[(a)] Define what it means for a metric space $(X,d)$ to be \emph{complete}. Give a metric $d$ on the interval $I=(0,1]$ such that $(I,d)$ is complete and such that a subset of $I$ is open with respect to $d$ if and only if it is open with respect to the Euclidean metric on $I$. Be sure to prove that $d$ has the required properties.
\item[(b)] Let $(X,d)$ be a complete metric space.
\begin{enumerate}
\item[(i)] If $Y\subset X$, show that $Y$ taken with the subspace metric is complete if and only if $Y$ is closed in $X$.
\item[(ii)] Let $f:X\to X$ and suppose that there is a number $\lambda\in(0,1)$ such that $d(f(x),f(y))\leq\lambda d(x,y)$ for every $x,y\in X$. Show that there is a unique point $x_0\in X$ such that $f(x_0)=x_0$.
\end{enumerate}
Deduce that if $(a_n)$ is a sequence of points in $X$ converging to a point $a\ne x_0$, then there are integers $\ell$ and $m\geq\ell$ such that $f(a_m)\ne a_n$ for every $n\geq\ell$.
\end{enumerate}
```
