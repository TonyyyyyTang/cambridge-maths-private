## Question (verbatim question.tex)
```latex
\begin{enumerate}
\item[(a)]
\begin{enumerate}
\item[(i)] Suppose a random variable $X$ has unknown density $p$. State the Neyman--Pearson lemma for testing the null $H_0:p=f$ against the alternative $H_1:p=g$, where $f$ and $g$ are continuous densities with the same support.
\item[(ii)] Suppose $X_1,\ldots,X_n\overset{\mathrm{i.i.d.}}{\sim}N(\mu,1)$. Find, with justification, a uniformly most powerful test for testing
\[
H_0:\mu=0,\quad\text{against}\quad H_1:\mu>0,
\]
that has size $\alpha\in(0,1)$. Express the critical region in terms of the cumulative distribution function $\Phi$ of the $N(0,1)$ distribution. Argue moreover that your test is also a uniformly most powerful size $\alpha$ test for testing
\[
H_0:\mu\le0,\quad\text{against}\quad H_1:\mu>0.
\]
\end{enumerate}
\item[(b)]
\begin{enumerate}
\item[(i)] Consider the setting of part (a) (i) but where we modify the null hypothesis $H_0$ to be that $p\in\{f_1,f_2\}$, with the alternative unchanged (again $f_1,f_2$ are continuous with the same support as $g$). Given $\pi\in[0,1]$, let $\phi$ be the size $\alpha$ likelihood ratio test for the null $H_{0,\pi}$ that $p=\pi f_1+(1-\pi)f_2$, against $H_1$. Suppose that in fact $\phi$ has size $\alpha$ for the null hypothesis $H_0$. Explain why $\phi$ must be uniformly most powerful for $H_0$ against $H_1$.
\item[(ii)] A certain drug requires the logarithm $\mu$ of the relative concentrations of two chemicals to be within a range $[-\mu_0,\mu_0]$, for $\mu_0>0$. A new cheaper method for manufacturing the drug has been proposed for which it is claimed that $\mu=0$, but there is concern that $\mu\notin[-\mu_0,\mu_0]$. The value of $\mu$ cannot be measured directly, but a single measurement $X\sim N(\mu,1)$ is available. Consider therefore testing
\[
H_0:\mu\notin[-\mu_0,\mu_0],\quad\text{against}\quad H_1:\mu=0,
\]
based on $X$. Given $\alpha\in(0,1)$, let $z>0$ be such that
\[
\Phi(z-\mu_0)-\Phi(-z-\mu_0)=\alpha.
\]
Show that the test which rejects $H_0$ when $X\in[-z,z]$ is uniformly most powerful.
\end{enumerate}
\end{enumerate}
```
